# 오프닝 컷 — 넣는 법

`0.webp` ~ `4.webp` (또는 .png/.jpg) 로 저장하면 코드 수정 없이 붙는다.
없으면 색면 + 큰 활자로 폴백하므로 **한 장도 없어도 인트로는 돈다.**

| 파일 | 자막이 말하는 것 | 그려야 할 것 |
|---|---|---|
| `0` | 어젯밤, ○○ 호텔 | 비 내리는 밤의 호텔 외관. 창 몇 개만 불이 켜짐 |
| `1` | 22:20. 12층 복도의 불이 반쯤 나가 있었다 | 어두운 호텔 복도. 형광등 하나가 깜빡이는 느낌 |
| `2` | ○○호에서 ○○가 숨진 채 발견됐다 | 반쯤 열린 객실 문. 안에서 빛이 새어나옴. **시신은 보이지 않게** |
| `3` | 호텔에 남아 있던 다섯 사람 | 로비에 선 다섯 실루엣. 얼굴은 어둠에 잠김 |
| `4` | 그중 한 명이 범인이다 | 책상 위에 펼쳐진 사건 파일과 다섯 장의 사진 |

## 규격
- **가로 16:9**, 1536×864 이상
- **webp, 장당 200KB 이하.** 5장이면 1MB 미만 — 첫 화면이므로 무게가 곧 체감이다
- 어둡게. 자막이 위에 얹히므로 화면 아래 1/3은 특히 어두워야 한다

## 왜 사건별 그림이 아닌가
사건은 시드로 매번 생성된다(제목·호텔·피해자·다섯 명의 직업이 전부 달라짐).
그래서 **그림은 어느 사건에도 맞게 범용으로, 구체적인 것은 자막이** 진다.
그림에 특정 이름이나 호수를 그려 넣으면 다른 시드에서 거짓말이 된다.

## 프롬프트 공통 접미사
> cinematic still, photorealistic, night, heavy rain-soaked mood, deep shadows,
> warm tungsten against cold blue, film grain, 35mm, no text, no watermark,
> bottom third of the frame must stay dark for subtitles, 16:9
