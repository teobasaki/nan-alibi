# FIVE ALIBIS (nan-alibi)

**매 판 다른 사건이 생성되고, LLM이 연기하는 용의자 5명을 심문해 3~5분 안에 범인을 지목하는 브라우저 추리게임.**
NAN 2026 사전과제 제출물.

- 플레이: **https://nan-alibi.pages.dev**
- 시연용 고정 시드(60초 대본, [docs/DEMO.md](docs/DEMO.md)): **https://nan-alibi.pages.dev/?seed=36**

---

## 무엇을 만들었나

**연극 3막 구조**로 한 판이 굴러간다.

**제1막 — 30초의 현장.** 커튼이 열리면 감식반이 철수하기 전의 사건 현장(미술관)에 서 있다.
5초의 훑기로 무엇이 어디 있는지 눈에 익히고, **30초 안에 가방 다섯 칸**을 채워야 한다.
현장의 기록은 다섯 칸보다 많다 — **무엇을 포기할지 고르는 것이 곧 수사의 시작**이다.

**제2막 — 경찰서.** 다시 커튼이 닫혔다 열리면 경찰서다. 자유롭게 돌아다니고, `I` 키를 누르면
수사일지가 책처럼 펼쳐진다. 용의자 프로필 카드에서 한 명을 고르면 취조실로 넘어간다.

5개 시각 슬롯에서 다섯 명이 각자 어디에 있었는지 진술한다. 그중 한 명은 범인이고,
무고한 사람도 자기 비밀 때문에 거짓말을 한다. 플레이어는 **한 사람당 대화 10회**라는 상한 안에서
심문하고, 현장에서 주워 온 기록과 진술이 어긋나는 지점을 찾아 **범인(60점)·동기(15점)·수단(15점)**
세 축을 지목한다. 카드끼리 맞대어 모순을 확인하는 행위는 무료다 — 예산은 정보를 **얻는** 데만 쓴다.

사건은 시드에서 결정론적으로 생성된다. 생성기가 뱉은 사건은 검증기 V1~V7(범인 유일성, 결정적 증거 도달 가능성,
선행조건 사슬, 무고한 자의 거짓말 등)을 통과해야만 플레이에 들어간다. 같은 시드는 서버와 클라이언트에서
같은 사건을 만들어내므로, 사건 전체를 네트워크로 보낼 필요가 없다.

**판정은 끝까지 시스템이 하지 않는다.** 상황판은 인물×시각, 장소×시각, 인물별 조서 세 각도로 같은 데이터를
보여주지만, 어느 칸이 모순인지 미리 붉게 칠해주지 않는다(ADR 017). 그걸 대신 해주면 이 게임에 남는 추론 행위가 없다.

## AI를 어디에 썼나 — 두 층

**런타임 층**은 좁다. `gpt-4o`(프로덕션 실측 중앙값 1.34~1.40초, ADR 020 — terra 에서 내렸다. 더 싸고 더 빨랐다)가
하는 일은 페르소나 8종 중 배정된 성격으로 **대사·조서를 연기하는 것뿐**이다. 조사 예산 소모, 카드 해금,
동요 수치, 최종 채점은 전부 `src/engine/game.ts`의 순수 함수가 소유한다 — LLM이 돌려주는 `pressureDelta`나
`revealedFactIds`가 게임 상태로 들어가는 경로는 코드에 아예 없다. 응답은 화이트리스트(그 인물이 아는 사실 id만),
사건에 없는 시각·방번호 차단, 160자 상한의 3중 검증기를 통과해야 화면에 오르고, 실패하면 1회 재요청 →
페르소나별 사전 작성 대사로 떨어진다. 그리고 **폴백이 뜨면 차감했던 조사 1회를 통째로 롤백한다**
(`src/main.ts:942`, `973`) — AI가 실패했는데 플레이어가 대가를 치르면 그건 버그가 아니라 배신이다.

**제작 층**은 넓다. 그리고 **버린 것까지 기록에 남겼다.**
용의자 8종을 Meshy(multi-image-to-3d + 오토리깅)로 생성해 한동안 썼지만, 오토리그의 다리 본 8개가
Mixamo 대비 축이 180° 롤되어 무릎이 뒤로 꺾였다. 런타임 보정으로 버티다 결국 **기성 리깅 배우 5종으로
전량 교체**했다(CC BY, [CREDITS.md](CREDITS.md)). 대신 어느 리그에나 Mixamo 클립을 구울 수 있는
리타게팅 파이프라인이 남았다 — Blender 헤드리스(`scripts/retarget.py`)에 본 이름 정규화와 타 규약
매핑표(CC_Base·carla 계열)를 넣어 매핑 0개를 23개로 살렸다.

효과음 21종은 프롬프트를 **코드에 명세로 박제**했다(`src/ui/sfxSpec.ts` — 어느 순간에 나는 소리인지,
무슨 정보를 실어 나르는지를 프롬프트보다 먼저 적는다). VARCO Text-to-Sound로 19종을 굽고,
제공 크레딧이 소진된 뒤에는 로컬 ComfyUI + Stable Audio 3 Small로 같은 프롬프트를 재생성해
dev 전용 A/B 시청실에서 귀로 골랐다. 인트로·엔딩 만화 22장과 초상은 ChatGPT 이미지 생성이 맡았다.
화면 품질은 `gpt-5.6-sol`에게 "칭찬하지 마라, 몇으로 바꾸라고 말하라"는 아트 디렉터 페르소나를 주고
실제 렌더를 깎게 해 6건 중 3건을 코드에 반영했다(카메라 2.05m→1.35m, FOV 46°→37° 등, 커밋 `9222dd7`).
밸런스는 봇 3종의 승률로, 플레이 결함은 `npm run review`의 자동 플레이테스트 루프로 잡았다 — 정답을 모르는
리뷰어가 지적하고, **연속 3회 무지적일 때만** 수렴으로 친다(한 번 0건을 수렴이라 선언한 직후 같은 빌드가
5건을 냈기 때문이다).

> 전체 구조·프롬프트 조립·검증기 코드 경로·실측 수치는 **[docs/AI-ARCHITECTURE.md](docs/AI-ARCHITECTURE.md)** 에 있다.

음성은 **3층**이다. 서버 TTS(Supertone) → 브라우저 내장 `SpeechSynthesis` → 무음.
서버 TTS는 비스트리밍이라 LLM 뒤에 직렬로 붙이면 첫소리가 늦는데, **자막은 소리를 기다리지 않게** 해서
지연이 플레이를 막지 않는다(`src/ui/voice.ts`). 효과음도 파일이 없으면 WebAudio 합성으로 폴백한다 —
**에셋이 하나도 없어도 게임은 끝까지 돌아간다**는 것이 이 프로젝트의 폴백 원칙이다.

## 빠른 실행법

```bash
npm ci
npm test          # vitest — 21개 파일 301건, 약 4초
npm run dev       # http://localhost:5181 (주의: AI 경로는 안 돈다, 아래 참고)
npm run build     # tsc --noEmit && vite build
npm run verify    # test + functions 타입체크 + build (pre-commit 훅이 그대로 실행한다)
```

AI 응답까지 로컬에서 보려면 Cloudflare Function이 필요하다:

```bash
echo 'OPENAI_API_KEY=sk-...' > .dev.vars   # gitignore 되어 있다
npm run build && npm run cf:dev            # wrangler pages dev
```

**`npm run dev`(vite)에는 Function이 없어 `/api/interrogate`가 404 → 폴백 → 조사 환불로 처리된다.**
즉 심문으로 열리는 화면은 로컬 vite에서 끝까지 검증되지 않는다. 한 번 이걸 렌더 버그로 오진한 적이 있어
STATE.md에 상시 경고로 올려두었다.

기타: `npm run audit:persona`(라이브 LLM 8회 호출, 페르소나 변별력 감사) · `npm run review`(자동 플레이테스트 루프) ·
`npm run gen:pool`(시드 풀 재생성) · `npm run deploy`(Cloudflare Pages). CI(Node 22)는 `npm test → typecheck:functions → build`를 돌린다.

## 외부 에셋

취조실·미술관·용의자 배우 5종·증거 소품은 Sketchfab의 기성 에셋이다.
**12건 전부 원본 페이지와 라이선스를 확인했고 모두 CC BY 4.0이다** — 제목·저작자·URL·변형 내역을
[CREDITS.md](CREDITS.md)에 적었다.

확인 과정에서 **비상업(NC) 조건인 에셋 2건을 발견해 걷어냈다.** 필름 릴은 같은 물건의 CC BY 모델로
교체했고, 용의자 한 명은 다른 배우로 갈아끼웠다. 이 저장소의 원칙은 하나다 —
**출처가 확인되지 않은 에셋은 배포하지 않는다.** 확인하지 못한 캐릭터 3종을 자체 생성본으로
되돌린 이력도 CREDITS에 그대로 남겼다.

런타임에 외부 호스트를 부르는 곳이 하나 있다: Draco 압축된 GLB를 풀기 위한 디코더를 `gstatic.com`에서 받는다.
차단되면 3D가 뜨지 않고 2D 사진으로 폴백한다(게임은 그대로 돈다).

## 아직 안 된 것

숨기지 않고 적는다. 전체 목록은 [docs/STATE.md](docs/STATE.md)의 "안 되는 것 / 막힌 것" 절에 있다.

- **E1(사람의 실제 플레이 시간) 미측정.** 봇 기준 4분 57초는 있지만 사람이 한 판을 끝까지 돌린 기록이 없다.
- **취조실 3D 카메라가 인물에 지나치게 붙는다.** 팀 비주얼 바이블이 정한 프레이밍(눈높이·pitch ±3°·
  FOV 28~36°·인물 점유 40~48%)에 아직 맞추지 못했다.
- **수첩 내용이 새로고침에 살아남지 않는다.** 대화·조서는 메모리에만 있다(설정·여정 기록만 localStorage).
- **프롬프트 캐시는 미측정이다.** 당초 "입력 666토큰이라 최소 1,024를 못 넘는다" 고 판단했으나, 재측정하니 프리픽스가 median 1,257자(약 1,120토큰)로 자라 있었다. cached_tokens 를 실제로 찍어본 적이 없다 — docs/AI-ARCHITECTURE.md §3.3.
  비용·지연 모두 예산 안이라 프리픽스를 억지로 늘리지 않고 의도적으로 방치했다(ADR 005).
- 배우 5종의 화풍이 완전히 고르지는 않다. 서로 다른 제작자의 기성 리깅 모델이라 재질 표현이 조금씩 다르다.
  (Meshy 생성본이 섞여 있던 문제는 전량 교체로 해결했다.)
