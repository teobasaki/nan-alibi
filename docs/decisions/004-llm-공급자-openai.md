# 004 — LLM 공급자를 OpenAI 로 (모델: gpt-5.6-terra)

- 날짜: 2026-08-05
- 상태: 채택

## 맥락

기획서 §9 와 ADR 002 는 Anthropic Messages API 를 전제로 작성됐다.
그런데 팀이 실제로 보유한 것은 **OpenAI 키**였고 (로컬 `.env` 6곳에서 4종 발견, 전부 `sk-proj-` 형식),
Anthropic 키는 없었다. 마감 2일 상황에서 새 벤더 계정·결제를 트는 비용이 이득보다 크다.

## 결정

**OpenAI Responses API, 기본 모델 `gpt-5.6-terra`.**
`OPENAI_API_KEY` 를 Cloudflare Pages Secret 으로 등록했다 (production).

## 근거

계정에서 실제 사용 가능한 모델을 조회해 확인한 것 (기억이나 웹 요약이 아니라 `/v1/models` 응답 기준):
gpt-5.6 계열 3종(sol/terra/luna) 전부 사용 가능.

| 모델 | 입력/출력 ($/1M) | 판당 추정 | 판정 |
|---|---|---|---|
| gpt-5.6-sol | 5 / 30 | ~$0.11 | 과함 — 대사 3문장에 플래그십은 낭비 |
| **gpt-5.6-terra** | **2 / 12** | **~$0.04** | **채택** — 예산 $0.15 대비 여유 3배 |
| gpt-5.6-luna | 0.20 / 1.20 | ~$0.004 | 비용 폭주 시 강등 경로로 남긴다 |

**전환 손실이 예상보다 작았다.** 우려했던 캐시 제어는 살아 있다:
- **프롬프트 캐시 수동 제어 가능** — GPT-5.6+ 는 `prompt_cache_breakpoint` 로 캐시 지점을 명시할 수 있다.
  최소 프리픽스 1,024 토큰이고 우리 페르소나 프리픽스는 약 1.5k 라 **자격을 충족**한다.
  캐시 히트 확인은 `usage.input_tokens_details.cached_tokens`.
- **구조화 출력** — `text.format = { type:'json_schema', name, schema, strict:true }`. 동등.
- **스트리밍** — 지원. 동등.

**유일한 실손실은 프리워밍이다.** OpenAI 에는 `max_tokens: 0` 프리필 같은 예열 수단이 없다
(캐시는 실제 요청으로만 채워진다). 기획서 §7 검산 3 의 "브리핑 40초 무료 구간에 5인 프리픽스 굽기" 는 폐기한다.

## 버린 대안

- **Anthropic 키 신규 발급**: 계정·결제 세팅 + 잔액 충전이 마감 이틀 전 리스크다. 키가 이미 있는 쪽이 이긴다.
- **양쪽 지원 (프로바이더 추상화)**: 추상화 계층 + 양쪽 테스트로 반나절~하루. 마감에 그 시간이 없다.
  단일 공급자로 가되 **호출부를 `llm.ts` 한 파일에 가둬** 나중 교체 비용을 낮춘다.
- **gpt-5.6-sol**: 판당 $0.11 로 예산 안이지만, 출력이 3문장/250토큰이라 플래그십의 이점이 거의 안 나온다.
- **gpt-4o 계열**: 5.6 대비 캐시 제어(`prompt_cache_breakpoint`)가 없다.

## 영향

- `functions/api/*` 의 환경변수: `ANTHROPIC_API_KEY` → `OPENAI_API_KEY`.
- 기획서 §9 기술 스택, §7 검산 4(비용), §8 에이전트 설계서의 스키마 표기를 OpenAI 형식으로 갱신.
- **프리워밍 폐기** → 첫 심문만 캐시 미스로 1~2초 느리다. 완화책: 사건 브리핑 화면에서
  첫 용의자의 프리픽스로 **실제 첫 호출을 미리 시작**해 둔다 (프리워밍은 아니지만 체감은 비슷).
- 키 출처: 로컬 `.env` 중 동작 확인된 것(HTTP 200, 모델 126종). **beyond-frame 프로젝트의 키를 재사용**했으므로
  과금이 그 프로젝트와 섞인다 — 분리가 필요하면 전용 키를 발급해 교체한다.
