# 029 — 연극 3막 구조: 커튼 전환·경찰서 자유이동 기본·I 키 인벤토리

- 날짜: 2026-08-10
- 상태: 채택

## 맥락 (어떤 문제·제약이 있었나)

이 게임은 이미 장면이 셋이었다 — 코믹 인트로(발단) · 30초의 현장 · 경찰서/취조실.
그런데 **그 사이를 페이드아웃이 잇고 있었다.** 페이드는 "화면이 바뀐다" 만 말하고
"장면이 바뀐다" 는 말하지 않는다. 더 나쁜 것은 그 다음이었다: 3D 씬이 서는 데
2~4초가 걸리는데, 그동안 관객에게 **"현장으로 이동 중…" 로딩 문구**를 보여주고 있었다.
무대 전환을 객석에서 구경시킨 셈이다.

두 번째 문제는 **제2막의 기본 화면**이었다. 현장이 끝나면 책상(알리바이 격자)이 서고,
3D 경찰서는 인덱스 탭을 눌러야 들어가는 옵션이었다. 만들어 놓고 안 쓰는 방이 된다.

세 번째는 **수사일지를 볼 자리**였다. 일지는 우면(`.nb-journal`)에 항상 떠 있었는데,
제2막의 기본이 3D 경찰서가 되면 걷는 동안 그것이 화면에서 사라진다.
게임에서 그 물건의 이름은 인벤토리고, 관습적인 열쇠는 I 다.

## 결정

**연극 3막의 문법을 화면에 그대로 세운다.**

1. **커튼 전환** (`src/ui/curtain.ts`, 신규) — 붉은 벨벳 두 폭이 닫혔다 열린다.
   `curtainSwap({ title, sub, onClosed, play })` 한 함수. 전환 지점은 두 곳:
   브리핑 카운트다운 종료 → 제1막(현장), 현장 종료 → 제2막(경찰서).
   **무대 교체는 `onClosed` 안에서만** 일어난다 — 3D 마운트가 커튼 뒤로 숨는다.
   그림은 CSS 그라디언트(에셋 0장), 소리는 호출부가 넘긴 `play('curtain')`.
2. **경찰서 자유 이동이 제2막의 기본** (`enterStation()`) — 커튼이 오르면 그 방에 서 있다.
   책상·카드 월은 [← 카드 월] 로 언제든 돌아간다. 걷기/경찰서 모델이 없으면 아무 일도
   하지 않는다 (예전대로 책상이 선다).
3. **I = 인벤토리** — 수사일지가 양면 스프레드로 펼쳐진다. 좌면은 기존 `journalLines`,
   우면은 이미 손에 쥔 것(가방·남은 후보·모순·잔여 조사). **새 정보는 없다.**
   현장(30초) 중과 서류 오버레이·인트로가 떠 있을 때는 열리지 않는다.
4. **카드 월은 한 벌이 쫙 펼쳐진다** — 자리마다 `--dx`·`--fan` 을 주어 가운데 덩이에서
   좌우로 퍼진다.

## 근거 (왜)

- 커튼은 **대기 시간을 연출로 산다.** 같은 2~4초가 "기다림" 에서 "막간" 으로 읽힌다.
  로딩 문구를 없앤 것이 아니라 관객이 볼 이유가 없어진 것이다.
- 커튼은 **반드시 열린다**: `onClosed` 가 던지든 늦든 `maxHold`(8초) 뒤에는 걷힌다.
  연출이 게임을 막으면 그건 연출이 아니라 장애물이다 (`journal3d` 와 같은 원칙).
- 책은 **웹사이트가 아니라 물건이어야 한다.** 스크롤 패널로 만들면 이 게임이 지켜 온
  은유(수첩·기록철·인장)가 그 순간만 깨진다. 질감은 3D 수첩이 쓰던 바로 그
  `public/nb/{leather,paper}.webp` 를 재사용해 DOM 책과 3D 책이 같은 물건으로 읽히게 했다.
- `paper.webp` 는 3D 수첩의 **UV 아틀라스**라 `cover` 로 늘리면 여러 장의 필기 이미지
  이음매가 그대로 보인다(실측 — 첫 구현이 정확히 그랬다). `.nb-page` 가 쓰는 문법
  그대로 512 타일 반복 + 아주 낮은 농도로 깐다.

## 버린 대안 (그리고 왜 버렸나) — 필수

- **페이드 유지 + 로딩 문구 다듬기**: 문구를 아무리 잘 써도 관객은 무대 전환을 보고 있다.
  문제는 문장이 아니라 **보여주고 있다는 사실**이었다.
- **커튼을 3D(Three.js)로**: 현장·경찰서 씬과 렌더러를 공유해야 하고, 정작 커튼이 필요한
  순간은 **씬이 아직 없거나 막 파괴된 순간**이다. CSS 오버레이는 그 두 순간 모두에 선다.
- **커튼이 열릴 때까지 게임 진행을 막기(await)**: 마운트가 실패하면 영영 안 열린다.
  `Promise.race` 로 상한을 두고, 늦으면 로딩 상태 그대로 막을 올린다.
- **인벤토리를 우면 패널의 확대 토글로**: 같은 정보를 같은 그릇에 두 크기로 두는 것이라
  "펼친다" 는 동작이 은유를 얻지 못한다. 책이어야 I 가 인벤토리로 읽힌다.
- **경찰서를 제2막의 유일한 화면으로(책상 제거)**: 알리바이 격자는 이 게임의 상황판이고
  QA 가 "항상 보여야 한다" 고 지적한 바로 그 물건이다. 순서를 바꿨을 뿐 없애지 않았다.
- **인벤토리 키를 Tab/Esc 로**: Tab 은 이 게임의 키보드 접근성 동선이고 Esc 는 이미
  스왑·인트로 건너뛰기가 쓴다. I 는 비어 있었고 관습적이다.

## 영향 (이 결정으로 바뀌는 것)

- `src/ui/curtain.ts` 신규 — sound.ts 를 import 하지 않는다(헤드리스에서도 선다).
- `src/main.ts`: `openCrimeScene(fallback, ready?)` 에 `ready` 콜백이 생겼다 —
  "무대가 다 섰다" 는 신호이고 커튼이 그것으로 열린다.
- 제2막 진입 순서: 커튼 닫힘 → 씬 파기 · `timeUp` · `syncChapter` · `enterStation` → 커튼 열림.
  수사 정리 시트는 예전처럼 그 위에 열린다(막이 오르면 책상 위에 서류가 있다).
- 새 CSS 블록 셋: `.curtain*`, `.book*`, 그리고 R2 의 `.brf*`.
