# ADR 028 — 현장 씬 개편 라운드 세칙 (Joe·1인칭 기본·kind 서사 앵커)

- 날짜: 2026-08-10
- 상태: 채택 (구현 커밋 a529ea9, 에셋은 메인 세션 2def3a4)
- 관련: ADR 026·027, 사용자 결정 3건(액터 Joe 확정·1인칭 기본·개연성 배치)

사용자 결정이 계약이고, 구현하며 계약이 답하지 않은 지점을 여기 남긴다. 엔진(engine/)은 무변경이다.

## 1. Joe 는 네이티브 — 보정도, 키 가드의 클립 인출도 다르게 지난다

Joe(Mixamo 네이티브 베이크)는 `NATIVE_SLUGS` 로 표시하고 **unrollLegs 를 걸지 않는다**
(다리 축 180° 롤은 리타게팅 파이프라인의 결함이라, 네이티브에 걸면 멀쩡한 다리를 뒤집는다).
기존 슬러그 액터는 폴백으로 남고 보정도 유지된다.

- 버린 대안: 전 액터 공통 보정 후 Joe 만 예외 각도 — Joe 의 본 이름이
  `mixamorig7:` 접두라 LEG_BONES 매칭이 안 돼 사실상 no-op 이지만, "우연히 무해"에
  기대지 않고 명시적으로 건너뛴다.

## 2. joe.run 은 키 가드에 걸린다 — run **클립만** 뽑는 2단 폴백

실측: `joe.run.opt.glb` 이 키 30.78m 로 재진다 (security.run 의 31.26m 와 같은
Beta_Surface류 잔여 — ADR 026 §7 의 그 함정). 가드가 몸으로 쓰기를 거부하면
**joe.walk 몸에 run 클립만 본 이름 바인딩으로 얹고** 속도를 3.4 로 올린다.
클립 인출의 키 가드는 네이티브에서 건너뛴다 — 그 가드는 리타게팅 잔여물을 잡는
장치인데, 클립만 쓸 때는 겉껍데기 메시 크기가 오탐을 낸다. 실측: 달리기 자세 정상.

- 버린 대안: ① 가드 상한을 40m 로 완화 — 진짜 드러누운 거인도 통과시킨다.
  ② run 파일 재수출 대기 — 마감일이다. 파일이 고쳐지면 1단에서 그냥 잡힌다.

## 3. 배치는 장소 축이 아니라 kind 서사 앵커다 — spawnFor 는 계약 테스트용 존치

"한곳에 뭉치거나 무작위"라는 실플레이 불만의 수리. `spawnAnchored` 가
cctv→벽 상단(2.2~2.6m 부착)·call→데스크/벤치 위·receipt→데스크/수장고 곁·
autopsy→사망 지점 옆·keycard→수장고 구석으로 편다. 같은 kind 는 순번대로 다른
앵커, 앵커 소진분은 마지막 앵커 둘레 결정론 고리. 좌표는 전부 갤러리 실측
(GLB 노드 t: Statue 7.90/-0.14, chairs 4.53/-0.04 + 오프셋)에서 골랐다.

- 버린 대안: spawnFor 를 kind 인자로 확장 — 기획서 ⑥-⑧ 계약 테스트(장소 축)가
  그 함수를 잠그고 있어, 본선 교체 대신 병렬 신설로 계약을 지켰다.

## 4. 부착(mounted) 마커는 도달성 재배치를 면제받는다

벽·가구 위는 "설 수 없는 자리"가 정상이므로 씬의 spotFor(빈 칸 나선 이동)를
건너뛴다. 줍기는 원래 발치 XZ 반경(1.1m) 판정이라 규칙은 그대로다. 발치 링(halo)은
바닥에 남아 "여기 서면 닿는다"를 말한다.

## 5. 1인칭 기본, 클릭 이동은 몸이 돈다 — 조감은 V 와 훑기가 진다

`firstPerson = true` 가 기본. 키 이동은 몸 기준(A/D 조향)이지만 **클릭 이동은
목표 기준으로 몸을 돌린다** — 안 돌리면 시선 고정 옆걸음이 된다. 스폰 첫 시선은
홀 중심(출입문 벽이 첫인상이면 안 된다). 종료 국면도 1인칭을 유지해 화이트아웃
직전에 시점이 튀지 않는다. 십자선은 넣지 않았다 — 흰 윤곽빛+힌트바가 조준 신호다.

## 6. 사망 지점 연출 — 잿빛이 골든 케이스 §4 의 대비책이다

fallscene(단일 메시)은 부분 숨김이 불가하므로 색을 잿빛으로 눌러(lerp 0.55)
유혈류 요소가 있어도 톤이 죽게 했다. keycard 메탈 박스의 futuristic 색도 같은
문법(lerp 0.6)으로 무대에 맞춘다. crimetape 는 Plane 리본의 실측(y 2.37m 세로)을
허리 높이 0.3m 로 눕혀 사망 구역 4변에 두른다 — 실패하면 기존 링 테이프가 폴백.

## 7. 브리핑 버튼 연타 가드 (실측 수리)

[수사를 시작한다] 는 페이드 0.4초 동안 한 번 더 눌린다. 두 번 열리면 첫 호스트가
고아 검은 캔버스로 보드를 덮는다 — 연타 재현으로 실측했고, explore3d 의 mounting
가드 문법으로 막았다 (`csOpening || csHandle` 이면 무시).

## 8. 실플레이 피드백 4건의 실측 판정 (커밋 4408360)

- **"충돌 미적용"** — 재현 실패가 결론이다: 파티션 밀기(슬라이드로 우회, 관통 0)·
  벤치(정점 클러스터 8곳 전부 막힘)·조각상 막힘을 실측했다. 다만 도달성 probe 는
  격자가 통째로 비어도 통과하므로 **역방향 검증**(조각상·벤치·파티션이 안 막히면
  DEV 경고)을 베이크 직후에 박았다. 함정 하나: 벤치 검증 좌표를 chairs **노드
  원점**으로 찍으면 벤치 사이 빈 바닥이라 오탐이다 — 정점 클러스터 실측 좌표를 쓴다.
- **joe.run 재베이크** — 파일은 갱신됐는데 브라우저 HTTP 캐시가 옛 GLB 를 물고
  있었다 (`cache:'reload'` 갱신 후 가드 통과, 달리기 몸 직행). §2 의 2단 폴백은
  안전망으로 남는다. 배포에서도 GLB 는 해시 없는 public 경로다 — 재배포 후
  이상하면 캐시부터 의심하라.
- **"집기 미재생"** — 클립은 돌고 있었다. 정체는 대기 클립(ADR 027 §5, 집기보다
  늦게 태어남)과의 **반반 블렌딩** — playPickup 이 walk 만 0 으로 누르고 idle 을
  안 눌러 집기가 묽어졌다. idle 도 즉시 0 (weight 실측 {running:true, idleW:0}).
  1인칭에서는 몸 자체가 안 보이므로 **카메라 숙임**(0.38m 사인, 모션 축소 제외)이
  그 몸짓을 진다.
- **수거 직관** — 토스트 1.5s("확보 — 검시 소견 · 22:20 1204호" — kindLabel·
  slotLabel 경유, 월드 어휘 준수)·슬롯 hover 툴팁·1~5키 칸 확인·kind 아이콘 자리
  (evidence/<kind>.webp 도착 시 자동). 버린 대안: 수거 모달 — 30초 게임에서
  시간을 멈추지 않는 모든 표시는 지나가는 것이어야 한다.

## 알려진 흠 (수리 대상, 규칙 아님)

- 1인칭에서 벽 상단 cctv 는 바로 밑에 서면 수직 화각(±30°) 밖일 수 있다 —
  발치 링·힌트바·훑기 점멸이 보완한다. 불편 보고가 오면 y 하한(2.2)으로 내린다.
- 천장을 숨긴 채라 1인칭 상방이 검다 — 불 꺼진 갤러리 무드로 읽히지만,
  여유가 생기면 천장을 1인칭에서만 되살리는 분기를 검토한다.
- seed 36 은 cctv 5장이라 2장이 앵커 초과분으로 북동 코너 바닥에 선다 —
  "벽 상단" 서사가 3장까지만 성립한다.
