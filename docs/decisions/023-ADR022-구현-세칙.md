# ADR 023 — ADR 022 구현에서 내린 세칙 4건

- 날짜: 2026-08-10
- 상태: 채택 (구현 커밋 1c435ad · 88e8ca6 · 1ec3ff0)
- 관련: ADR 022(팀 UX 계약 교체), ADR 007(카운팅 방지), ADR 009(옛 예산)

ADR 022 는 계약을 정했고, 구현하며 계약이 답하지 않은 지점 4곳을 결정했다.

## 1. 챕터 종료는 "예산 0" 또는 "기록 고갈" — 둘 다다

즉시 조회 가능한 기록이 4건뿐인 시드가 있다(gate 사슬은 앵커까지 잠근다).
예산 0 만을 게이트 조건으로 삼으면 그 시드에서 심문이 **영영 안 열린다.**
`fieldDone()` 은 두 조건의 OR 이고, 심문 중 해금으로 값이 되돌아갈 수 있으므로
UI 는 첫 true 를 걸쇠(`ui.chapter2`)로 잡는다.

- 버린 대안: 생성기가 즉시 조회 기록 ≥5 를 보장 — 사건 구조를 건드린다.
  ADR 022 가 명시적으로 금지한 영역이다.

## 2. 예산 소진 후 해금 기록(requires>0)은 무료 조회

잠긴 카드키 기록의 선행 조건(자백성 진술·목격자 증언)은 전부 심문 챕터에서
모이는데, 심문 챕터는 정의상 현장 예산 0 에서 시작한다. 조회가 예산을 요구하면
통찰 보너스(+10)는 **구조적으로 불가능**해진다. 자물쇠를 여는 값(대화)은 이미
치렀다 — 조회는 보상을 집는 동작이다. 선행 조건 없는 기록은 그대로 막는다.

- 버린 대안: 심문 챕터에 별도 조회 예산 1~2회 — 지갑이 셋이 되고, 그 예산을
  아껴야 하는지가 새 혼란이 된다.

## 3. 밸런스 목표 구간 60~75% → 75~95%, 무작위 봇은 지목도 무작위로

대화 지갑 분리(인당 10회, 총 50회)로 정보가 흔해져 상식 봇이 64% → **84%**.
이것은 회귀가 아니라 ADR 022 §2 가 감수한 관대함이다 — 난이도의 긴장은 승패가
아니라 3축 완답과 통찰 보너스로 옮겨 갔다. 상한 95% 는 "심문 없이 확정되는"
구조 누설(ADR 007 의 병) 재발 감시용으로 잠근다.

무작위 봇이 똑똑한 지목 사다리를 타면 51% 를 "추리" 한다 — 하한선(운으로 몇 %)의
의미가 죽어서, 지목을 남은 후보 중 무작위로 바꿨다. 실측 22% (눈감고 20% + 2%p).

## 4. 범인 채점의 후보 눈금(60/50/40) 폐기

축이 하나(범인)던 시절의 찍기 방지 장치였다. 3축에서는 셋 다 찍을 확률이 1/125 라
눈금 없이도 만점이 찍기를 배제한다. 서사("좁혀서 맞혔는가")는 결과 화면 문장으로
남긴다 — 점수와 서사를 분리한 것이지 서사를 버린 게 아니다.

- 버린 대안: 눈금 유지 — 60점 만점 축에 40~60 세 칸이면 동기·도구(각 15점)와의
  비율이 판마다 흔들려 "무엇이 중요한 게임인가" 가 흐려진다.
