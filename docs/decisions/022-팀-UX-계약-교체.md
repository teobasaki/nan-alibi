# ADR 022 — 팀 UX 변경안 수용: 챕터 구조·3축 추론·자백 재구성

- 날짜: 2026-08-10
- 상태: 채택 (팀원 기획 문서 접수 → 적대적 검증 → 계약 교체)
- 관련: ADR 009(예산), ADR 008(결정적 증거), 기획서 v1

## 새 계약 (팀안 그대로)

시작 페이지 → 발단 카툰 → **증거 수집(현장 조사 5회)** → 수사 정리 →
**심문(용의자당 대화 10회 상한)** → **최종 추론(범인·동기·살인 도구)** →
정답(자백+5단계 재구성)/오답(비스포일러 진단) 엔딩 → Retry/새 게임.

유지: 5명 중 범인 1, AI 는 진실·판정을 바꾸지 않는다, 페르소나 반응, 비스포일러 오답.

## 적대적 검증에서 걸러낸 것 (팀안과의 협상 지점)

1. **살인 도구 축은 카드키 체계와 충돌한다.** 기존 수단 20점·잠긴 기록·재현영상이
   전부 "수단 = 카드키 발급 구분" 위에 서 있다. → 도구를 **새 축**으로 추가하고
   (WEAPONS 5종 + 검시 소견 단서), 카드키 잠긴 기록은 **통찰 보너스**로 강등한다.
   재현영상 자막은 도구 언급 없이 성립하므로 그대로 산다.
2. **대화 10회는 상한이지 의무가 아니다.** 5명×10회를 다 쓰면 LLM 50회
   (판당 ~$0.25, 15~25분). 팀안의 "새 플레이 시간 기준 필요" 는 이렇게 답한다 —
   숙련자는 심문 몇 번으로 끝낼 수 있고, 상한은 낭비를 막는 안전선이다.
3. **"보드 중심 탈피" 를 격자 삭제로 읽지 않는다.** 알리바이 대조표는 소거 규칙의
   엔진이다. 격자는 형사수첩 안의 한 페이지로 남고, **흐름의 중심**만 챕터로 옮긴다.
4. **사건 현장 3D 에셋이 없다** (현재 공간은 경찰서). 오늘은 기존 공간을 쓰고
   마커 명칭만 현장 감식으로 맞춘다. 호텔 12층 에셋은 제출 후.

## 버린 대안

- **자백을 LLM 으로 생성** — 엔딩이 네트워크·검증 실패에 노출된다. 마지막 화면이
  폴백으로 끝나면 게임 전체가 폴백으로 기억된다. 페르소나별 결정론 템플릿으로 간다.
- **동기를 자유 보기(6종 고정 목록)로** — 추리가 아니라 어휘 맞히기가 된다.
  동기는 **용의자별로 하나씩** 배정하고(범인의 것이 정답), 심문에서 관계를 캐면
  드러나게 한다 — 이미 있는 관계·비밀 구조를 그대로 태운다.
- **격자 삭제** — 위 3번. 삭제하면 "기록만이 사람을 지운다" 규칙의 화면이 사라진다.
