# ADR 025 — 월드 팩은 사건이 아니라 스킨이다

- 날짜: 2026-08-10
- 상태: 채택 (구현 커밋 3c11ebc · 25e02fc · 79a30ab)
- 관련: ADR 024(GC001 세칙), C1 월드 라벨 간접화(8ef3c0e)

## 결정

경매장·방송국·극장은 **생성된 사건 위에 입히는 라벨 스킨**(applyWorld)이다.
생성기·검증기는 무접촉 — 직업·관계·장소 라벨·장소명·직함·제목만 갈아입고,
궤적·거짓말·증거·해금·채점 축은 JSON 단위로 동일하다 (tests/worlds.test.ts 잠금).
선택은 URL(`?world=`)이 지고, 모르는 id 는 원본으로 떨어진다.

- 버린 대안: 월드별 caseGen 분기 — 유일해 보장(V1~V7·봇 밸런스)을 무대 수만큼
  복제·재측정해야 한다. 무대가 늘 때마다 밸런스 빚이 늘어나는 구조다.
- 버린 대안: 기록 종류·무기까지 월드화 — 지시대로 유지. 카드키·CCTV·1960년대
  무기는 세 무대 모두 성립하고, 바꾸면 WEAPON_TRACE 1:1 과 금칙어 규율을
  무대마다 다시 세워야 한다.

## 서버는 옷을 알아야 한다 (잠복 버그의 정체)

서버(functions/api)는 시드로 사건을 재생성한다 — 시드만 보내면 프롬프트가
호텔 어휘로 조립돼, 갤러리·경매장 화면 앞에서 페르소나가 다른 세계의 말을 한다.
**gc001 이 이미 그 상태였다** (C2 에서 놓친 잠복 버그). 요청에 world·caseId 를
실어 서버가 같은 옷을 입게 했고, 캐시 키에도 옷을 포함했다.

## 직업→모델 매핑은 테스트가 지킨다

gc001 에서 갤러리 직업이 SLUG_BY_JOB 에 없어 3D 가 **에러 없이 조용히** 죽었다
(경찰서 탭 실종·취조실 사진 폴백). 이 함정은 새 월드마다 재발하므로
"모든 월드 직업은 매핑 존재 + 한 사건 안 slug 5종 상이" 를 테스트로 잠갔다.
