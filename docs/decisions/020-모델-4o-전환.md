# ADR 020 — 심문 모델을 `gpt-5.6-terra` → `gpt-4o` 로 내린다

- 날짜: 2026-08-09
- 상태: 채택
- 관련: [ADR 004](004-llm-공급자.md) · [ADR 005](005-openai-호출-파라미터.md)

## 배경

판당 40~50회를 호출한다. 대사 생성에 **추론이 필요 없다는 것은 ADR 005 가 이미 확인**했다 —
`effort=none` 이 기본보다 오히려 빨랐고 품질이 같았다.
추론을 안 쓰는 작업에 추론 모델의 단가를 낼 이유가 없다.

## 결정

기본 모델을 **`gpt-4o`** 로 한다. `OPENAI_MODEL` 환경변수로 배포 없이 덮을 수 있게 했다.

### 같이 고쳐야 했던 것 — 모델명만 바꾸면 전 판이 폴백이 된다

호출은 `/v1/responses` 에 `reasoning: { effort: 'none' }` 을 실어 보내고 있었다.
4o 계열에 이 필드를 보내면 **400** 이다. 실측:

```
gpt-4o + reasoning  → 400  "Unsupported parameter: 'reasoning.effort' is not supported with this model."
gpt-4o             → 200
```

그래서 `supportsReasoning(model)` 로 **모델명과 파라미터가 함께 움직이게** 했다.
이 한 줄을 안 고쳤으면 모든 심문이 조용히 폴백 대사로 떨어졌을 것이다 —
폴백은 조사 횟수를 소모하지 않으므로 **오류처럼 보이지도 않는다.**

## 근거 — 속도가 아니라 검증 통과율로 골랐다

`scripts/bench-model.ts` 가 **진짜 프롬프트와 진짜 검증기**로 30턴을 돌린다
(시드 36·77 × 용의자 3명 × 질문 5개). 2회 반복 실측:

| 모델 | 1회차 | 2회차 | 지연 중앙값 |
|---|---|---|---|
| **gpt-4o** | 30/30 | **30/30** | **1341~1399ms** |
| gpt-4o-mini | 30/30 | **28/30** | 1484~1660ms |
| gpt-5.6-terra | 30/30 | 30/30 | 1708~1756ms |

4o 는 terra 보다 **싸고 빠르고** 통과율이 같다.

## 버린 대안

- **`gpt-4o-mini`** — 가장 싸고 1회차엔 100% 였다. 그런데 2회차에 `unknown-fact` 로 두 번 떨어졌다
  (없는 사실을 지어냈다). 이 게임의 검증기는 그걸 잡아 폴백으로 보내고, 폴백 두 번은
  그 판의 재미를 깎는다. **한 번의 통과를 근거로 모델을 고르지 않는다.**
  다시 쓰고 싶으면 `OPENAI_MODEL=gpt-4o-mini` 한 줄이면 된다.
- **terra 유지** — 품질은 같은데 더 비싸고 더 느렸다. 남길 이유가 없었다.
- **모델을 상수로 박아 두기** — 심사 중에 문제가 생기면 재배포가 필요하다.
  환경변수 스위치가 그 위험을 없앤다.

## 되돌리는 법

```
npx wrangler pages secret put OPENAI_MODEL   # gpt-5.6-terra 입력
```
