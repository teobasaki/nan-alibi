# ADR 013 — 시각 정체성: 알리바이 격자를 주인공으로

## 맥락
기능은 완성됐지만 화면에 정체성이 없었다. frontend-design 스킬의 자기진단에 걸렸다 —
기존 팔레트(중성 검정 #0e0d12 + 앰버 단색)는 스킬이 명시한 **AI 기본값 3종 중 2번**
("거의 검정 배경 + 밝은 액센트 하나") 그 자체였다. 어느 게임에 붙여도 똑같았을 화면이다.

## 결정

### ① 색은 템플릿이 아니라 허구에서 뽑는다
무대는 22:20, 불이 반쯤 꺼진 호텔 12층이다. 그 세계의 물건에서 색을 가져왔다.

| 토큰 | 값 | 출처 |
|---|---|---|
| `--bg` | `#16110f` | 불 꺼진 복도 (중성 검정이 아니라 갈색기) |
| `--panel` | `#201519` | 호텔 카펫 |
| `--amber` | `#c8912f` | 놋쇠 문패 — 자원·주목 |
| `--green` | `#4f9b6e` | 비상구 유도등 — 확인됨 |
| `--red` | `#b3372c` | 인장 붉은색 — 모순 |
| `--ink` | `#e9e1d3` | 조서 용지 |

액센트를 **둘**로 쓴다(놋쇠=주목 / 비상구=확인됨). 단색 액센트가 기본값의 핵심이었다.

### ② 서체는 역할이 셋이다
조서는 명조(`AppleMyungjo, Batang, Nanum Myeongjo`), 본문은 고딕,
**시각·기록번호는 고정폭** — 그것들은 문장이 아니라 데이터이기 때문이다.

### ③ 시그니처 — 알리바이 대조표
이 게임의 추리는 처음부터 "누가·언제·어디" 의 5×5 표였다.
그런데 그 표가 카드 더미와 대화 로그에 흩어져 있어서 플레이어가 머릿속에서 다시 그려야 했다.
표를 화면 한가운데에 세우고, **범행 시각 열만 놋쇠 괘선으로 세로 관통**시켰다.
모순이 잡히면 그 칸에 붉은 **인장(印)** 이 찍힌다.

**격자 칸이 곧 진술 카드다.** 이전에는 같은 진술이 왼쪽 용의자 카드·오른쪽 보유 카드에
중복돼 화면에 세 번 나왔다. 격자에서 바로 집게 하니 중복이 사라지고,
연결이 "표 위의 한 칸을 짚는" 공간적 행동이 됐다.

## 버린 대안
- **조서 용지 질감(크림 배경 + 세리프 + 붉은 도장)**: 스킬이 지목한 AI 기본값 1번. 주제에 맞아 보이지만 그래서 더 위험하다.
- **감시 단말 CRT(인광 녹색)**: 기본값 2번의 다른 색일 뿐.
- **game-designer 스킬의 "바이럴 스펙터클"(파티클·화면흔들림·3초 폭발)**: 읽기 중심 추리게임에 해롭다. 12항목 채점 구조와 팔레트·위계·피드백 원칙만 취했다.

## 함께 고친 것
- 한글에 걸린 `letter-spacing`(2px·3px) 제거 — "알 리 바 이", "기 록 조 회" 로 벌어져 있었다. 자간·대문자화는 라틴 전용 장식이다.
- 이모지 얼굴(👤/🙂/😰) → 놋쇠 문패에 새긴 성(姓). 다섯 명이 전부 같은 얼굴이라 정체성을 오히려 지우고 있었다.
- 내부 id 노출(`E1 기록과 어긋난다`) → `CCTV · 22:20 라운지 기록과 어긋난다`.
- 압박 게이지가 0일 때 빈 막대만 그리던 것 → 값이 있을 때만, 말로("흔들린다").

## 2차 패스 — 서류철 하나로 묶기
브리핑·제출·결과가 각자 다른 카드처럼 보였다. 셋 다 `fileHeader()` 를 쓰게 해
**사건번호(=시드) + 강력 3팀 + 붉은 인장** 을 머리에 단다. 시드가 사건번호라는 게
"재현 가능한 게임" 이라는 사실을 세계관 안에서도 말이 되게 한다.

인장은 판정에 따라 색이 갈린다 — `수사 개시`·`송치 의견`·`사건 해결` 은 붉은색,
`미제 편철` 은 회색(`.cold`). 붉은 인장은 '확정' 의 색이라 못 맞혔을 때 쓰면 거짓말이 된다.

낡은 안내 하나를 함께 고쳤다: 브리핑 1번이 "왼쪽 카드에 22:20 주장이 적혀 있다" 였는데
진술은 이미 가운데 격자로 옮겨간 뒤였다. 다섯 항목을 새 조작에 맞춰 다시 썼다.

## 품질 바닥선
- **좁은 화면(≤900px)**: 3단 → 세로 적층. 이전에는 한 줄에 한 글자씩 쪼개졌다 —
  "덜 좋은 것" 이 아니라 "안 되는 것" 이었다.
- **`prefers-reduced-motion`**: CSS 전역 + 타이핑 연출은 JS 라서 `matchMedia` 로 직접 존중.
- 키보드 포커스는 격자 칸까지 확장 (`role=button` · `tabIndex` · `aria-pressed`).
