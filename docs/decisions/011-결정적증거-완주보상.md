# ADR 011 — 결정적 증거는 승리 조건이 아니라 완주 보상

## 맥락
자동 리뷰가 3판 연속 "범인을 맞혀도 결정적 증거를 못 얻고 끝난다 → 승패가
되돌릴 수 없는 증거 선택으로 갈린다" 를 major/blocker 로 올렸다.

## 측정
상식 봇 100판: 범인 적중 64%, **결정적 증거 도달 26%.**
봇이 후반 4회를 사슬 해금에 쓰도록 고쳐 봤더니 범인 적중이 64%→52% 로 떨어졌다.
두 목표가 9회를 두고 **경쟁**한다는 뜻이다.

## 결정
경쟁 자체를 없애지 않는다. 대신 **역할을 명시**한다.
- 승리 조건은 범인 적중(60점) 하나다.
- 결정적 증거(20점)는 도달률 26% 짜리 상급 목표로 둔다.
- 제출 화면에 "못 맞혀도 범인만 맞히면 해결" 을 적는다.

## 버린 대안
- **예산 9→11**: 두 목표를 다 주면 자원 긴장이 사라진다. 3~5분 세션도 깨진다.
- **해금 사슬 단축**: 사슬이 이 게임의 유일한 다단 추리다. 없애면 남는 게 소거뿐이다.
- **봇 후반 사슬 추적**: 측정으로 기각됨(승률 -12%p).

## 리뷰 하네스 교훈 (4번째 반복)
리뷰어가 "승패가 증거로 갈린다" 고 본 건 **내가 배점을 안 줬기 때문**이다.
제출 3요소·예산·상단바에 이어 네 번째다 — 지적이 이상하면 먼저 내 로그를 의심한다.

## 추가 (라운드 9~10)
리뷰어가 blocker 2건으로 잡은 "22:10 기록이 결정적 증거로 제출됐다" 는 **정당한 지적**이었다.
UI 는 범행 시각 기록만 고르게 막았는데 봇의 `finish()` 가 그 제약을 우회하고 있었다.
봇이 화면 규칙을 우회하면 그 로그는 게임을 대표하지 못한다 → 봇에 같은 제약을 걸었다.
