# GC001 「옮겨진 상자의 사각」 발단 카툰 — 생성 프롬프트

> 골든 케이스 001(라음 사립 갤러리, 관장 한라온 사망)의 오프닝 카툰 10장.
> 감정선은 팀 UX 계약 그대로: **평온함(3) → 위화감(3) → 충격(2) → 호기심(2)**.
> 스타일은 기존 인트로와 같은 연필 누아르 — 단, 이 사건은 현대 갤러리라
> 1960년대·전자기기 금지 조항은 **이 세트에 한해 해제**한다(출입 패널·카메라가 플롯이다).

## 🚨 하드 제약 (골든 케이스 문서 §4 + 기존 규칙)

1. **글자 금지** — 라벨·시리얼·간판 전부 빈 종이 또는 뭉갠 흔적. `REV-17-084` 를 그림에 새기지 않는다.
2. **얼굴 금지** — 실루엣·뒷모습·손·그림자만. 다섯 용의자 캐스팅은 3D 가 진다.
3. **시신·수단 묘사 금지** — 골든 케이스는 "구체 신체 부위·도구·손상 기전을 truth·텍스트·asset 어디에도 넣지 않는다".
   발견 장면은 **받침대 뒤로 가려진 그림자와 흩어진 서류**까지만. 혈흔 금지.
4. 전부 **1536×1024 가로**, 중요한 내용은 세로 가운데 띠.

## 공통 스타일 블록

```
Hand-drawn detective adventure game illustration: loose confident pencil line
art with rotoscope-like figure work, sketchy cross-hatching and charcoal grain
shading, mostly desaturated warm sepia monochrome with selective muted color
accents only in brass amber and deep burgundy, aged paper texture feeling,
dramatic lighting with deep shadows, cinematic composition. Setting: an elegant
modern private art gallery at night. No text, no lettering, no readable labels
or signage, no watermark, no speech bubbles, no frames or borders. 1536x1024.
```

## 충격 — 2장

```
[STYLE] Seen from far across the dark exhibition hall: a single dramatic
```

```
Grainy, urgent, shocking.
```
