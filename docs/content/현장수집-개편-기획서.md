# 개편 기획서 — 「30초의 현장」 (승인 대기)

> 팀 방향: 인트로 → **살해 현장(미술관)에서 30초 증거 수집**(60 Seconds! 문법) →
> 수집이 수사에 반영 → **용의자 프로필 카드 월** → 클릭 → 심문실.
> 이 문서가 승인되기 전까지 코드 0줄. (game-blueprint 규율)

## ⓪ 재미의 축

- **코어 판타지**: 감식반이 철수하기 전, 현장을 마지막으로 밟는 형사 — "무엇을 들고 나올 것인가."
- **30초 루프**: 훑는다 → 달린다 → 줍는다(가방 5칸) → 포기한다 → 호루라기.
  (수집 후에는 기존 루프가 이어받는다: 기록 대조 → 심문 → 지목)

기존 게임의 핵심 문장 "무엇을 포기할지가 수사다"를 **버튼 5번에서 몸의 30초로 물리화**하는 개편이다.
엔진 계약(FIELD_BUDGET 5·TALK_CAP 10·3축·잠긴 기록)은 **한 글자도 안 바뀐다** —
수집된 증거품 = 기존 기록 카드(ui.game.cards)와 1:1. 시간이 UI 계층에서 예산을 연출할 뿐이다.

## ② 자원·경제 규칙

- **시간 30.0초** (시작 전 5초 훑기 — 카메라가 현장을 한 바퀴, 조작 불가, 증거 위치 노출)
- **가방 5칸** = FIELD_BUDGET. 6번째 줍기 → 스왑 모달("무엇을 내려놓겠습니까") — 내려놓기도 1.5초 소모
- 시간 종료 = 예산 0 (챕터 게이트 조건 그대로: 소진 → 수사 정리 → 심문 개방)
- 못 주운 기록은 그 판에서 열람 불가 — **기존 규칙과 동일한 결과, 다른 연출**
- 접근성: `?calm=1` 이면 타이머 없음(가방 5칸만) — reduced-motion 사용자·심사위원 데모용

## ③ 시간 압박 곡선 (적 AI 대체물)

| 구간 | 연출 |
|---|---|
| 훑기 5초 | 카메라 오빗 1회전, 증거 마커 전부 점멸 1회 |
| 30~11초 | 초시계 째깍(1Hz), 상단 필름 카운터 |
| 10~6초 | 째깍 2Hz, 비네트 서서히 조임 |
| 5~0초 | **심박음** + 비네트 강, 타이머 붉게 |
| 0초 | 호루라기 — "감식반 철수" 자막, 화면 화이트아웃 → 수사 정리 |

## ④ 조작

기존 그대로: WASD/방향키 이동 · E/Space 줍기 · V 1인칭. 신규: 가방 가득 시 E → 스왑 모달(1~5 숫자키/클릭).

## 종이 시뮬레이션 (검산)

- 이동 2.2m/s · 방 12×9m · 증거 10개 평균 간격 3.2m
- 개당 비용 = 이동 1.5s + 판독(이름표 읽기) 1.3s + 수거 0.4s ≈ **3.2s**
- 30초 ÷ 3.2s ≈ **9.4개 (완주선)** — 최적 동선·즉단 기준
- 초견 플레이어(라벨 읽고 고민): 개당 ~5s → **6개 언저리** → 가방 5칸과 정합.
  "다 주울 수는 있을 것 같은데 손이 모자라다"는 감각 = 60 Seconds! 의 그 감각
- 실패 하한: 3개만 주워도 심문+증언 해금으로 만회 가능 (기존 밸런스가 보장 — common 봇 84%가 그 증거)
- 판 전체 길이: 훑기 5s + 수집 30s + 정리 ~20s + 카드 ~10s + 심문 3~8분 + 지목 ≈ **5~10분 유지**

## 범위

- **MVP(오늘)**: 현장 씬(타이머+가방+수거) · 카드 월 · 매핑 · calm 모드 · 완료 기준 전부
- **v1(오늘 중 여유 시)**: 훑기 카메라 오빗 · 폴라로이드 연출 · 심박/비네트 · 스왑 모달(없으면 "가방이 가득하다" 거절)
- **주차장(약속 아님)**: 월드별 현장 지오메트리 변형 · 증거품 실3D 모델 · 현장 발자국/혈흔 아님 흔적 연출 · 리플레이 고스트

## 위험

1. **마감일 당일 대개편** — 기존 배포본이 안전판(롤백 가능). MVP 실패 시 기존 흐름으로 제출.
2. 현장이 gc001 서사(갤러리)와 시드 사건(호텔 등) 사이에서 어긋남 — 현장 지오메트리는 "추상 현장" 하나, 라벨은 월드 소유(기존 문법).
3. 30초가 심사 데모에서 너무 빠를 수 있음 — `?calm=1` 로 해소.
