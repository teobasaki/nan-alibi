# VARCO 사운드 생성 대장 — 파일 ↔ 프롬프트 페어

> 파일 위치: `public/sfx/*.opus` (게임이 그대로 재생). VARCO는 길이 지정 없이 ~4초 WAV를 돌려주므로
> 명세 길이로 트림+페이드 후 opus 변환했고 **원본 WAV는 보존하지 않았다** — 재생성: `node scripts/gen-sfx.mjs --only <key>`.
> 프롬프트 정본은 `src/ui/sfxSpec.ts` (이 표는 그 사본이다). ComfyUI(Stable Audio 3 SFX) 비교 시
> 앞에 `TrackType: SFX,` 접두와 뒤에 `clean isolated one-shot` 를 붙이면 팀 명세 형식과 맞는다.
