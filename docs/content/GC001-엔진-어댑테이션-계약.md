## 0. 원칙

1. **유일해 논리를 보존한다** — 문서 §15: 소거로 {류나린·배지호·문소라}까지 좁고,
   결정적 기록(REV-17-084)+상자 동선 연결이 류나린만 남긴다.
2. **수단·신체·도구 묘사 금지** (문서 §4) — gc001 에서는 검시 흔적·도구명을 전부
   추상 분류("고의적 직접 물리력")로 대체한다. 유혈 서술 금지.
3. 실제 사건·인물·기관 참조 금지. 모든 이름은 정본 그대로 (가상).
4. 엔진 계약(FIELD_BUDGET 5·TALK_CAP 10·3축 60/15/15·챕터 게이트)은 그대로 탄다.

## 1. 월드 라벨 간접화 (전역 상수 → 사건 소유)

`CaseFile` 에 선택 필드 `world` 를 추가한다. 없으면 기존 호텔 상수를 쓴다(시드 사건 무변화).

```ts
world?: {
  slotLabels: readonly [string,string,string,string,string]
  placeLabels: readonly [string,string,string,string,string]
  /** 기록 종류 표시명 덮어쓰기 (없는 키는 기본) */
  kindLabels?: Partial<Record<Evidence['kind'], string>>
  /** 3축 셋째 축의 표시명(기본 '살인 도구')과 선택지 5종 */
  weaponAxisLabel?: string
  weaponOptions?: readonly string[]
  /** autopsy 기록의 소견 본문 (기본 WEAPON_TRACE[weapon]) */
  autopsyText?: string
}
```

- 헬퍼 `slotLabel(c, s)` / `placeLabel(c, p)` / `kindLabel(c, k)` 를 두고
  SLOT_LABEL/PLACE_LABEL 직접 참조(10파일)를 전부 이 헬퍼로 바꾼다.
- UI 하드코딩("호텔에 남아 있던", 브리핑 문구, 코치 문구)을 CASE 필드 기반으로.
  `grep -rn "호텔\|1204" src/` 가 잔여 목록이다 (names/config/roleSlug 는 시드 사건 전용이라 무방).

## 2. gc001 고정 사건 (`src/data/gc001.ts`)

생성기를 타지 않는 **수제 CaseFile**. `seed: 1`(고정), Retry 는 자연히 같은 사건.

궤적 거짓말쟁이(lieSlots 비어 있지 않은 무고인) ≥2: **배지호·문소라** (V6 충족).
궤적 초안 (slot 0~4, 장소 index):

- 류나린 truth `[2,2,2,2,3]` / claim `[2,1,1,1,3]` (21:04 퇴장 주장, 21:22 재입장)
- 배지호 truth `[0,3,3,0,2]` / claim `[0,0,0,0,2]` (통화하러 반입 쪽 통로에 나감)
- 문소라 truth `[0,2,4,4,4]` / claim `[0,4,4,4,4]` (21:09 전시홀에서 상자 이동)
- 도율 truth=claim `[2,1,1,1,1]` (21:06 홀 점검 후 21:12 퇴장… slot0=2 는 20:40 점검의 잔상,
  검증기가 걸리면 `[0,1,1,1,1]` 로 조정 가능)
- 김하늘 truth=claim `[3,3,3,3,2]` (패널 점검, 21:21 호출로 전시홀)

**소거 목표**: 범행 시각(slot2) 기록으로 도율(갤러리 밖)·김하늘(반입문 앞)만 소거.
문소라·배지호는 slot2 확정 기록이 없어 남는다 → 결정적 기록 전 후보 {류나린,배지호,문소라} = 문서 §15.

### 기록 (Evidence — FIELD_BUDGET 5 대비 8~9건)

즉시 조회:
1. `receipt` slot2 place1 [도율] — 외부 도착 기록 (소거)
2. `receipt` slot2 place3 [김하늘] — 출입 패널 점검 기록 (소거)
3. `autopsy` slot2 place2 [] — 현장 판정 (수단 축 단서)
4. `call` slot0 place0 [] — 피해자 통화·해임 통지 출력 기록 (동기 축 정황, subjects 없음이
   엔진에서 문제면 [배지호] 로 데스크 목격 처리)
5. `receipt` slot1 place2 [문소라] — 상자 스캔·임시 표식 기록 (21:10 전시홀 = 문소라 거짓말 모순)
6. `receipt` slot3 place4 [문소라] — 반입대 고정 작업 기록 (**결정적 사슬의 반쪽**)
7. `call` slot2 place1 [] 또는 [배지호 제외] — 배지호 개인 통화 기록 (위치 비고정 명시,
   exhaustive=false — 배지호를 소거하지 **못하는** 기록)

해금(잠긴 기록):
8. `cctv` slot3 place2 [] — 21:18 카메라 조각: 얼굴 식별 불가, 어두운 랜야드.
   exhaustive=false. requires: [김하늘 증언(시야가 열렸었다)]
9. **결정적** `keycard` slot3 place2 [류나린] decisive=true,
   keyLabel `REV-17-084 · 21:11 류나린 수정 권한 발급`,
   requires: [카메라 조각(8), 반입대 작업 기록(6)] — 문서의 C-03(두 반쪽 연결)을
   잠금 사슬로 재현: 상자 동선과 카메라 조각을 다 쥐어야 라벨 대조가 열린다.

주의: 결정적 기록이 **범행 시각이 아니라 21:18(slot3)** 에 있다 — 은폐 시각이 범인을 가리키는
사건이다. 엔진이 결정적 기록을 CRIME_SLOT 에 가정하는 곳이 있으면 그 가정을 사건 데이터로 옮겨라.

### 증언·제시 (문서 §12 매핑)

- 김하늘에게 상자 기록(5 or 6) 제시 → 증언 "패널 점검 중 열린 시야를 놓쳤다" (→ 8 해금 열쇠)
- 문소라에게 상자 기록 제시 → 증언 "통로를 비우려 옮겼다. 라벨이 어긋난 건 내 탓이다"
- 류나린에게 카메라 조각 제시 → 증언 "REV-17-084 가 내 권한으로 발급된 건 맞다" (자백성 진술)
- 배지호 심문(관계) → 증언 "해임 통지 수신자는 류나린이었다" (동기 축 근거)

### 페르소나·자백
