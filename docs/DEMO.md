# DEMO — 60초 시연 대본 (NAN 2026)

> 확정 시드: **`36`** · 접속 URL: **`https://nan-alibi.pages.dev/?seed=36`**
> 재선정: `npm run demo:seed` (사전 검증 시드 풀 전체 스캔)
> 마지막 검증: 2026-08-05 · 엔진 재생으로 전 단계 확인 완료

## 1. 왜 시드 36인가

`scripts/pick-demo-seed.mjs` 로 **사전 검증 시드 풀(`src/data/pool.json`, 400개)** 전체를 스캔했다.
필수 3조건(상식 봇 승리 · 첫 모순 ≤4회 · ★반응 ≥1회)을 통과한 시드 중 시연 적합도 1위가 36이다.

| 조건 | 요구 | 시드 36 실측 | 판정 |
|---|---|---|---|
| ① 상식 봇이 이긴다 | 승리 | **승리** (범인 신하늘 적중) | ✅ |
| ② 첫 모순이 빨리 나온다 | ≤4회 | **2회차** — 첫 심문 직후 | ✅ |
| ③ ★반응(무언가 열림) | ≥1회 | **1회 · 3회차** | ✅ |
| ④ 결정적 증거 도달 | 가산점 | **적중** (E9 카드키 · 22:20 · 1204호) | ✅ |
| ⑤ 시연 길이 | 짧을수록 | **6회**에 결정적 증거 확보 (예산 9회 · 이론 최소 m\*=4) | ✅ |
| ⑥ 시작 대기 | 0초 | **사전 검증 풀 소속** — `attempts=1`, 생성 재시도 없음 | ✅ |
| — | — | **6회에서 제출 시 130점**(범인 60 · 수단 20 · 증거 20 · 잔여 조사 15 · 모순 15) | — |

**시연 길이를 봇의 소모 횟수(9회)로 재지 않았다.** 봇은 예산이 남으면 계속 파므로 어느 시드에서든
9회를 다 쓴다. 사람은 결정적 증거를 손에 쥔 순간 제출하면 되므로 **결정적 증거를 얻는 회차**가
실제 시연 길이다. 스크립트의 `demoScore` 는 이 기준으로 정렬한다.

**시드 36을 최종 선택한 결정적 이유는 ⑦번째 조건이다 — 화면에서 벌어지는 사건의 종류가 서로 다르다.**
이 판에는 성질이 다른 모순이 세 번 나온다:

1. **직접 모순** — "기록에는 복도인데 본인은 라운지이라 했다" (거짓말이 잡힌다)
2. **부재 모순** — "윤시윤: 라운지 구역 기록에 이 사람이 없다" (CCTV는 그 구역 인원을 남김없이 담으므로,
   *안 찍혔다*는 것이 곧 *없었다*는 증명이다)
3. **현장 모순** — "기록에는 1204호인데 본인은 복도이라 했다" (범행 현장에 있었다는 확정)

②번 부재 모순이 특히 중요하다. **그 화면 하나가 "이건 텍스트 어드벤처가 아니라 논리 엔진"이라는 걸
증명한다.** 그리고 그 모순이 지목한 윤시윤이 마침 자물쇠의 나머지 열쇠를 쥐고 있어서,
다음 행동이 화면 근거로 자연스럽게 이어진다 — 대본이 억지스럽지 않다.

**사건 개요 (진행자만 아는 정답):**
- 사건: *열두 시의 카드키* · 을지로 클래식 호텔 1204호 · 피해자 남기훈(경매사)
- 범행: **22:20 · 1204호** · 진범 **신하늘(S5, 투자자)** · 동기 불륜 사실의 폭로 위협
- 수단: **미리 복제해 둔 카드키** · 결정적 증거: **E9 카드키 기록 · 22:20 · 1204호**
- 자물쇠: E9 ← `T-SLIP`(신하늘의 자백성 진술) + `T-S3`(윤시윤의 증언)
- **해금 조합은 `E1 → 신하늘` 단 하나** (`presentUnlocks` 1건)

**용의자 5인 (시작 화면에 보이는 것):**

| | 이름 | 직업 / 관계 | 22:20 주장 | 페르소나 |
|---|---|---|---|---|
| S1 | 서지후 | 보안 팀장 / 당일 근무자 | 로비 | 계산적 |
| S2 | 한세아 | 전 동업자 / 3년 전 결별 | 직원계단 | 냉소적 |
| **S3** | **윤시윤** | **피해자의 비서** | **라운지** | 겁이 많음 |
| S4 | 신연우 | 보석 감정사 / 거래 중개 | 라운지 | 권위적 |
| **S5** | **신하늘** | **투자자 / 큰돈을 빌려줌** | **복도** | **감정적** |

## 2. 60초 대본

모든 단계는 **`commonsenseBot(36)` 이 실제로 밟은 순서**이며, 엔진으로 한 수씩 재생해 검증했다.
괄호 안 숫자는 그 행동 뒤 **남는 조사 횟수** — 화면 상단 ● 표시와 일치한다.

| 시각 | 화면 조작 | 말할 것 / 화면에 뜨는 것 |
|---|---|---|
| **0:00–0:06** | 시작 화면 그대로 | "다섯 명이 각자 22시 20분 알리바이를 댑니다. 조사는 **9회뿐**. 다섯 명 전원을 LLM이 연기합니다." |
| **0:06–0:09** | 오른쪽 **`CCTV · 22:10 복도`** (조사 8) | "범행 **직전** 시각부터 봅니다. 복도 CCTV에 **신하늘**이 찍혀 있습니다." |
| **0:09–0:19** | 가운데 **신하늘** 카드 → 질문칸에 `22시 10분에 어디 계셨습니까?` → [심문] (조사 7) | 신하늘이 **"라운지에 있었다"**고 답한다 |
| **0:19–0:24** | 왼쪽 보드에서 **`CCTV·22:10·복도`** 카드와 **신하늘의 22:10 진술** 카드를 연달아 클릭 (**무료**) | 붉은 인장 — **"신하늘: 기록에는 복도인데 본인은 라운지이라 했다"** → "**연결은 조사를 소모하지 않습니다.** 추론은 공짜입니다." |
| **0:24–0:34** | `CCTV·22:10·복도` 카드 **한 장만** 선택한 채 신하늘 대화창의 **[제시]** (조사 6) | ★ **"새로운 진술이 열렸다 — 잠긴 현장 기록 조건이 0/2 → 1/2로 진전됐다"** → "**이게 이 게임의 핵심입니다.** 모순을 들이밀면 AI가 흔들리고, 잠겨 있던 현장 기록이 열리기 시작합니다." |
| **0:34–0:37** | **`CCTV · 22:20 라운지`** (조사 5) | "남은 조건은 **관련자의 증언**. 두 사람이 22:20에 라운지라고 했는데 —" |
| **0:37–0:41** | `CCTV·22:20·라운지` 카드와 **윤시윤의 22:20 진술** 카드를 연달아 클릭 (**무료**) | 두 번째 인장 — **"윤시윤: 라운지 구역 기록에 이 사람이 없다"** → "**CCTV는 그 구역 전원을 담습니다. 안 찍혔다는 건 없었다는 뜻입니다.**" |
| **0:41–0:50** | **윤시윤** 심문 — `22시 20분에 정말 라운지에 계셨습니까?` (조사 4) | 오른쪽 **자물쇠가 사라진다** → "조건 2/2. **현장 기록이 열렸습니다.**" |
| **0:50–0:53** | 새로 뜬 **`카드키 기록 · 22:20 1204호`** (조사 3) | "범행 시각, 범행 현장. **신하늘의 카드키.**" |
| **0:53–0:56** | `카드키·22:20·1204호` 와 **신하늘의 22:20 진술** 연결 (**무료**) | 세 번째 인장 — **"신하늘: 기록에는 1204호인데 본인은 복도이라 했다"** |
| **0:56–1:00** | **제출** → 범인 `신하늘` / 수단 `미리 복제해 둔 카드키` / 결정적 증거 `카드키 기록 · 22:20 · 1204호` | 결과 **130점** → "조사 6회, **3회를 남기고** 끝냈습니다." |

**합계 60초.** 기계적 소요는 `tests/balance.test.ts` 의 `TIME` 상수 기준
**조회 2초 × 3 + LLM 왕복 9초 × 3 = 33초**뿐이다. 나머지 27초가 오프닝·연결 시연·제출·설명 여유이므로,
LLM이 실측 상단(p95 3.5초)까지 느려져도 **약 25초의 마진**이 남는다.

### 시간이 밀리면 — 어디를 잘라야 하나

**0:37–0:41 의 부재 모순 연결만은 자르지 마라.** 이 60초에서 가장 값비싼 4초다.
잘라도 되는 순서: ① 0:53–0:56 세 번째 연결 → ② 0:00–0:06 오프닝을 3초로 → ③ 0:19–0:24 첫 연결.
**조사 행동 6개는 하나도 못 뺀다** — 하나라도 빼면 자물쇠가 안 열린다.

## 3. 시연 직전 점검 (1분 전, 반드시)

1. **`/api/health` 가 `{ok:true, hasKey:true}` 인가.**
   `hasKey:false` 면 `/api/interrogate` 가 503 폴백을 내고, 클라이언트는 **행동을 통째로 롤백한다**
   (`src/main.ts` — `if (r.fallback) ui.game = before`).
   즉 **0:24 의 ★반응이 일어나지 않고 자물쇠가 영영 안 열린다.** 시연 전체가 무너지는 단일 지점이다.
2. URL에 **`?seed=36`** 이 실제로 붙어 있는가. 빠지면 랜덤 시드로 완전히 다른 사건이 뜬다.
3. 브라우저 콘솔 에러 0건.
4. 리허설을 돌렸다면 **새로고침** — 조사 횟수가 이미 깎여 있다.

## 4. 시연 중 절대 하지 말 것

- ❌ **즉흥 질문을 던지지 마라.** 위 두 질문만 쓴다. 질문이 무엇이든 **카드가 열리는 결과는 동일하지만**
  (판정은 엔진이 소유한다) 화면에 뜨는 *문장*은 매번 새로 생성된다. 엉뚱한 질문은
  "22:10 라운지"가 **대사로 못 박히는 순간**을 놓치게 하고, 그러면 바로 다음 연결이 밋밋해진다.
- ❌ **타이핑 연출이 끝날 때까지 기다리지 마라.** 답변은 28ms/글자로 찍힌다(긴 답변이면 4초 이상).
  연출 중에도 버튼은 이미 살아 있으므로(`ui.busy` 는 그 전에 풀린다) 말하면서 다음 행동으로 넘어간다.
- ❌ **다른 사람에게 증거를 제시하지 마라.** 이 사건의 해금 조합은 **`E1 → 신하늘` 단 하나**다.
  다른 조합은 전부 무반응이고 조사 1회가 그대로 날아간다. 예산이 6회로 짜여 있어 복구 불가다.
- ❌ **카드를 두 장 선택한 채 [제시]를 찾지 마라.** 두 장째를 누르는 순간 **자동으로 연결이 실행**된다.
  제시하려면 카드를 **정확히 한 장만** 선택한 상태여야 [제시] 버튼이 뜬다.
- ❌ **"AI가 범인을 자백했다"고 말하지 마라.** LLM은 승패에 손대지 않는다 — 판정·해금·점수는 전부 코드가 쥔다.
  자랑할 지점은 그 반대다: **"AI가 연기하지만 규칙은 코드가 소유해서 프롬프트로는 이길 수 없다."**
- ❌ **수단 20점을 "추리해서 맞혔다"고 말하지 마라.** 범행 수단은 5지선다 드롭다운이고,
  이 대본은 리허설된 정답을 고른 것이다. 질문받으면 정직하게 답한다.
- ❌ 결과 화면의 재시작(시드 재난수화) 버튼을 누르지 마라 — 데모 시드를 잃는다.

## 5. 재현

```bash
npm run demo:seed                      # 사전 검증 풀 전체 스캔 (권장 · 상위 후보 + 선정 시드 전체 봇 로그 출력)
npm run demo:seed -- 70000 600         # 풀 밖 임의 범위 스캔
FIRST_CONTRA_MAX=3 npm run demo:seed   # 더 빠른 "아하" 를 원하면 조건을 조인다
```

시연 시드를 바꾸면 **2절 대본을 통째로 다시 써야 한다** — 사건은 시드마다 완전히 다르다.
바꾼다면 풀(`●`) 안에서 고르라. 풀 밖 시드는 생성 재시도가 붙어 판 시작이 늦어질 수 있다.
