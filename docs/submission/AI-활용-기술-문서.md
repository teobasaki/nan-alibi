## 0. 한 줄

**AI는 연기하고, 사건의 진실과 승패 판정은 코드가 소유한다.**

이 게임에서 LLM이 하는 일은 정확히 하나다 — 배정된 성격으로 **용의자를 연기하는 것**.
조사 예산, 카드 해금, 동요 수치, 최종 채점은 전부 순수 함수가 가진다.
LLM이 돌려주는 값이 게임 상태로 들어가는 경로는 **코드에 아예 없다.**

이 문서는 그 경계를 어떻게 그었고, 프롬프트를 어떻게 썼고, 실패를 어떻게 다뤘는지 적는다.

## 1. AI를 쓴 곳 — 세 층

| 층 | 무엇을 | 도구 | 규모 |
|---|---|---|---|
| **런타임** | 용의자 페르소나 연기 (플레이 중 실시간) | OpenAI `gpt-4o` (Responses API, strict JSON) | 판당 40~50회 호출 |
| **런타임** | 음성 합성 | Supertone TTS → 브라우저 내장 → 무음 (3층 폴백) | 대사마다 |
| **제작** | 3D 캐릭터 · 효과음 · 이미지 · 리타게팅 | Meshy · VARCO · ComfyUI(Stable Audio 3) · ChatGPT · Mixamo | 아래 §5 |
| **평가** | 모델 벤치 · 페르소나 감사 · 자동 플레이테스트 | 자체 스크립트 + LLM | §6 |

## 2. 런타임 AI — 구조

```
플레이어 질문
   ↓
[클라이언트] 프롬프트 조립 — 그 인물이 아는 것만
   ↓
[Cloudflare Function] OpenAI 프록시  ← API 키는 여기서만 산다
   ↓
[검증기] 결정론 검사 11종 ── 실패 → 1회 재요청 → 폴백 대사 + 조사 횟수 환불
   ↓
[화면] 대사(타자기 연출) + 조서 한 줄 + 음성
```

### 2.1 진실을 주지 않는다

프롬프트에 들어가는 것은 그 용의자의 **주장(claim)** 뿐이다. **진실(truth)은 넣지 않는다.**

> 알려주면서 "말하지 마세요"라고 하는 것은 유출 설계다.

범인이 자기 진짜 위치를 모르면 프롬프트에서 새어나갈 경로 자체가 없다.
다른 용의자의 지식 시트도 같은 프롬프트에 절대 넣지 않는다.

### 2.2 거짓말은 AI가 지어내지 않는다

누가 어느 시간대에 거짓말하는지, 그 이유가 무엇인지는 **엔진이 시드에서 결정론적으로 고정**한다.
AI는 **어떻게 말할지**만 맡는다. 그래서 같은 시드는 언제나 같은 사건이고, 추리가 성립한다.

### 2.3 대사와 조서를 분리한다

플레이테스트에서 "대화는 풍부한데 사건이 진전되지 않는다"는 지적을 받았다.
플레이어가 대사에서 시간·장소·행동을 직접 뽑아내야 했기 때문이다.

그래서 **같은 호출에서 두 가지를 함께 받는다** — 추가 지연 0:

| 필드 | 무엇 |
|---|---|
| `speech` | 인물의 대사 (3문장·120자 이내) |
| `statement` | 조서: 시각 · 장소 · 행동 · 확신도(확언/추정/기억없음) · 새 정보 여부 |
| `revealedFactIds` | 이번 답변에서 언급한 사실 id — 시트 밖이면 응답째 폐기 |
| `pressureDelta` · `tell` | 동요 변화량 · 몸짓(시선/침묵/말더듬/언성) |

### 2.4 프롬프트 캐시

인물 프리픽스는 **판 내내 바이트 단위로 고정**이다. 타임스탬프·랜덤 id를 절대 넣지 않는다 —
한 바이트만 달라도 캐시가 통째로 죽는다. `prompt_cache_key`로 같은 인물을 묶어
2회차 호출부터 캐시가 붙는다.

### 2.5 모델 선택은 실측으로

| 시점 | 모델 | 근거 |
|---|---|---|
| 초기 | `gpt-5.6-terra` | — |
| 변경 | `gpt-4o` | 비용. 대사 생성에 추론이 필요 없음 (effort=none이 기본보다 **빠르고** 품질 동일) |
| 시도 | `gpt-5.4-mini` | 지연 감소 기대 |
| **복귀** | **`gpt-4o`** | **실측이 기각.** 프로덕션 3회 중앙값 mini 2624ms vs 4o **2066ms** |

> 바꾼 것만 적고 되돌린 것을 감추면 그건 기술 문서가 아니다.

## 3. 프롬프트 — 실제로 보낸 것

### 3.1 심문 페르소나 (판 내내 고정되는 프리픽스)

```text
당신은 살인 사건의 용의자로 심문받고 있다. 탐정의 질문에 인물로서 답하라.

[당신] {이름}, {나이}세, {직업}
- 피해자 {피해자}({직함})와의 관계: {관계}
- 피해자와 얽힌 사정: {동기}. 정면으로 물으면 인정하지 말되,
  관계를 이야기할 때 그 그늘이 배어나게 하라.
- 사건 장소: {장소}
- (거짓이 있으면) 당신에게는 남에게 알리고 싶지 않은 사정이 있다: {이유}.
  구체적 내용은 절대 먼저 말하지 마라.

[말투] {페르소나}
- 문장: {문장 스타일}
- 버릇: {말버릇} (매 문장 붙이지 말고 두세 번에 한 번만 — 기계처럼 들리면 실패다)
- 회피: {회피 방식}
- 압박 반응: {압박 반응}

[당신이 말할 수 있는 사실 — 이 목록이 전부다]
  F:{용의자}:{슬롯} = "{시간대}에 {장소}에 있었다"     ← 5칸 + 해금된 증언

[당신이 감추는 것]
  {거짓 슬롯} 항목은 사실이 아니다. 이유: {이유}

[규칙]
1. 위 목록에 없는 시각·장소·인물·사건을 절대 지어내지 마라.
2. 다른 용의자가 무엇을 아는지 당신은 모른다. 추측해서 말하지 마라.
3. revealedFactIds 에는 이번 답변에서 실제로 언급한 사실의 id 만 넣어라.
4. 답변은 2~3문장, 120자 이내. 인물의 말만 쓰고 지문·해설을 붙이지 마라.
5. 당신은 자신이 범인인지 아닌지 모른다고 가정하고 행동하라. 자백하지 마라.

[가장 중요한 규칙]
6. 묻는 것에만 답하라. 시각과 장소를 목록처럼 나열하지 마라.
   한 답변에 시각은 최대 1개만 언급한다.
7. 관계·감정·이유를 물으면 위치가 아니라 그 질문에 답하라.
   "말할 것이 없다" 로만 답하는 것은 이 심문에서 최악의 답변이다.
8. 같은 말을 반복하지 마라. 이미 한 말은 "아까 말씀드렸습니다" 로 줄여라.
9. 시각은 목록에 있는 값 그대로 하나만. 구간 표현("22:00부터 22:30까지") 금지.
```

**규칙 6~9가 따로 있는 이유 (플레이테스트 반영 이력)**
초기 버전은 1~5만 있었고, 두 가지가 실제로 깨졌다. 질문과 무관하게 알리바이를
**목록처럼 낭독**하는 것(정보 덤핑 — 심문의 긴장이 죽는다), 그리고 감정 질문에
"말할 것이 없다"로 **회피만 반복**하는 것(캐릭터가 죽는다).
6~9는 그 실패를 하나씩 막는 조항이고, 구간 표현 금지(9)는 검증기의 `time-range` 거부와 짝이다 —
**프롬프트로 막고, 새면 검증기가 잡는다.**

### 3.2 턴 가변부 (캐시되지 않는 부분)

```text
탐정: {이전 질문}
나: {이전 답변}
...
[탐정이 증거를 내밀었다] {증거 설명}      ← 제시했을 때만
탐정: {이번 질문}
(현재 당신의 동요 정도: {pressure}/100)
```

### 3.3 효과음 프롬프트 — 소리보다 먼저 무엇을 위한 소리인지 적는다

효과음 21종은 프롬프트를 **코드에 명세로 박제**했다. 각 항목이 갖는 것:
`어느 순간에 나는가` · `무슨 정보를 실어 나르는가` · `영문 프롬프트` · `길이(초)`.

```text
stamp — 모순이 확정돼 붉은 인장이 찍힐 때. 되돌릴 수 없는 판정.
  "A single heavy rubber stamp striking a stack of paper on a wooden desk.
   Sharp wooden thud with a brief paper crush, slight desk resonance, no reverb tail.
   Dry close-miked 1960s office. No music, no electronic tone."

deny — 연결했으나 모순이 아닐 때. 틀린 게 아니라 '이 조합이 아니다'.
  "A file folder closing softly on a desk. Muted paper flap, no click, no impact."
```

**공통 규칙:** 무대는 22:20의 취조실이므로 소리도 거기서 난다 — 금속·종이·나무·형광등.
**전자음은 쓰지 않는다. 이 게임엔 컴퓨터가 없다.** (모든 프롬프트가 `No music, no electronic tone`으로 끝나는 이유)

## 4. AI 출력을 그대로 믿지 않는다 — 검증기와 폴백

모든 응답은 **결정론 검증기**를 통과해야 화면에 오른다. 거부 사유 11종:

| 사유 | 무엇을 막나 |
|---|---|
| `shape` ×5 | 스키마 위반 · 필드 누락 · 형식 오류 |
| `too-long` | 대사 길이 상한 초과 |
| `unknown-fact` | **지식 시트 밖의 사실 id** — 유출 차단의 핵심 |
| `phantom-time` / `phantom-place` | 사건에 없는 시각·장소를 지어냄 |
| `time-range` | 구간 표현 (목록에 없는 주장이 된다) |

**폴백 3층:**
1. 검증 실패 → 1회 재요청 → 그래도 실패하면 페르소나별 사전 작성 대사
2. API 키 없음 → 즉시 폴백 (게임은 멈추지 않는다)
3. **폴백일 때 소모된 조사 횟수를 환불한다**

> AI가 실패했는데 플레이어가 대가를 치르면 그건 버그가 아니라 배신이다.

## 5. 제작에 쓴 AI — 채택과 폐기를 함께 적는다

| 시도 | 결과 | 판단 |
|---|---|---|
| **Meshy** multi-image-to-3d + 오토리깅으로 용의자 8종 생성 (레퍼런스 이미지는 `gpt-image-2`) | 생성 성공, **리깅 한계** — 다리 본 8개가 축 180° 롤되어 무릎 역굴절 | 런타임 보정으로 버티다 기성 리깅 배우로 교체 → 그 배우들도 상완 본 파손이 발견되어 **최종적으로 Meshy 착석본으로 복귀** |
| **Mixamo 리타게팅 자동화** (Blender 헤드리스) | 본 이름 정규화 + 타 규약 매핑표(CC_Base·carla)로 **매핑 0개 → 23개** 구제 | 채택. 어느 리그에나 클립을 굽는 파이프라인이 남았다 |
| **VARCO** Text-to-Sound | 효과음 19종 생성 | 채택 |
| **로컬 ComfyUI + Stable Audio 3 Small** (Apple Silicon) | VARCO 크레딧 소진 후 대체 경로. 모델 SHA-256 검증, 라이선스 확인 후 도입 | 채택. VARCO본과 **A/B 시청실**을 만들어 귀로 판정 |
| **ChatGPT 이미지 생성** | 인트로·엔딩 만화 22장, 연필 초상 | 채택. 그림이 없어도 색면 폴백으로 게임은 동작 |
| **3D 에셋 직접 렌더로 썸네일 굽기** | 증거 카드·인물 초상을 **런타임 모델 자체에서** 구움 | 채택. "2D 초상과 3D 인물이 다른 얼굴"인 문제가 원천적으로 없다 |

**공통 원칙: 생성 프롬프트는 대화 기록이 아니라 저장소에 남긴다.**
대화에만 있으면 같은 것을 다시 만들 수 없고, 왜 그것인지도 남지 않는다.

## 6. AI를 검증에도 썼다

- **`bench-model`** — 후보 모델·파라미터를 같은 픽스처로 돌려 지연·품질 비교 (§2.5 판단의 도구)
- **`persona-audit`** — 라이브 LLM 호출로 페르소나 변별력 감사 (시트 밖 발화·말투 붕괴 검출)
- **`review`** — 자동 플레이테스트 루프. **정답을 모르는 리뷰어**가 지적하고,
  **연속 3회 무지적일 때만** 수렴으로 친다 (한 번 0건을 수렴이라 선언한 직후 같은 빌드가 5건을 냈기 때문)
- **아트 디렉션 리뷰** — LLM에게 "칭찬하지 마라, 몇으로 바꾸라고 말하라"는 페르소나를 주고
  실제 렌더를 깎게 해 6건 중 3건을 코드에 반영 (카메라 2.05m→1.35m, FOV 46°→37°)

## 7. 사람이 결정한 것 — AI에 맡기지 않은 경계

- 사건의 진실 — 범인·동기·수단, 은폐 시각, 소거 사슬 설계
- 승패 판정과 3축 배점 (범인 60 / 동기 15 / 도구 15) — 순수 결정론 코드
- 콘텐츠 금칙 — 실제 사건·인물·기관 참조 금지, **수단·신체·유혈 묘사 금지**
- 에셋 채택/폐기와 라이선스 판정

> 마지막 항목의 실제 사례: 왕진 가방 에셋(CC BY, 라이선스 문제없음)에
> **톱과 붉은 액체 약병이 함께 모델링**되어 있어 금칙에 걸렸다. 카메라 각도로 가릴 수 없고
> 머티리얼 병합본이라 부분 삭제도 불가능해, 다른 가방으로 교체했다.
> **라이선스가 아니라 우리 콘텐츠 규칙 때문에 에셋을 바꾼 사례다.**
