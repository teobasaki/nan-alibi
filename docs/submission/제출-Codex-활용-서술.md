## Codex를 어디에 사용했나

**리팩터링과 안전망 구축**에 썼습니다. 게임 자체는 이미 동작했지만 `src/main.ts` 한 파일이
**3,181줄**까지 자라 있었습니다. 브리핑·현장·경찰서·취조실·수사·결과가 전부 그 안에 있었고,
**테스트가 한 줄도 닿지 않는 구간**이었습니다. 손대기 무서운 파일이 된 상태였습니다.

Codex CLI에 저장소를 넘길 때 `AGENTS.md`를 먼저 썼습니다. 여기에 **깨뜨리면 안 되는 불변식 7개**를
못박았습니다 — ①AI에게 사건의 진실을 주지 않는다 ②거짓말은 시드에서 고정되고 LLM이 지어내지 않는다
③LLM 출력은 검증기를 통과해야 화면에 오른다 ④채점은 순수 함수다 ⑤`Math.random()`을 쓰지 않는다
⑥시각·장소 라벨은 사건이 소유한다 ⑦수단·유혈 묘사 금지. **"이걸 건드리게 되면 멈추고 보고하라"**를
작업 규칙으로 넣었습니다.

그리고 `git worktree`로 **격리된 브랜치**에서만 작업하게 했습니다. 배포 중인 제출본이 `main`에 있었고,
실패해도 게임이 멀쩡해야 했기 때문입니다.

## 무엇을 구현했나

**커밋 8개, 약 30분.**

먼저 **특성 테스트**로 지금 동작을 박제하게 하고(선행 조건), 그다음 화면 단위로 갈랐습니다.
**동작 변경과 파일 이동을 같은 커밋에 섞지 말 것**을 규칙으로 걸어 커밋을 분리했습니다.

- `src/main.ts` **3,181줄 → 586줄**
- `src/screens/` 6개 모듈로 분리 — start 362 · crime-scene 233 · station 268 · result 566 ·
  interrogation 654 · investigation 965줄
- 테스트 **314건 → 324건**, `npm run verify`(테스트+타입체크+빌드) 초록 유지

## 어떤 문제를 해결했나

**"고쳤다"를 믿을 수 없는 문제**를 해결했습니다.

이 프로젝트에서 가장 비쌌던 실패는 전부 검증을 건너뛴 보고였습니다. 같은 이동 버그를 세 번
"고쳤다"고 보고받았는데 매번 원인이 달랐습니다(바닥 y가 0이 아니라 0.538 / 한 프레임이 0.25초를
통째로 적분 / 그림자 패스가 삼각형의 49%). 그래서 규칙을 세웠습니다 — **계측 없이 "고쳤다"라고
쓰지 않는다. 전/후 수치를 보고에 넣는다.**

Codex 결과물을 그대로 믿지 않고 **6개 축으로 리뷰**했습니다(동작 변경 혼입·불변식 침범·순환 참조·
생명주기·테스트 충분성·잔여 책임). 지적마다 **별도 에이전트가 반증을 시도**해 **50건 중 32건만**
남겼습니다. 틀린 지적 하나가 마감 직전에 멀쩡한 코드를 건드리게 만들기 때문입니다.

여기서 결정적인 사실이 나왔습니다. **특성 테스트 4건이 옮긴 함수 70개 중 43개를 한 번도 실행하지
않았습니다.** 함수마다 마커를 심어 계측해 확인했습니다. 그래서 폴백 시 조사 횟수 환불을 삭제해도,
챕터 게이트를 무력화해도, 이미 알려진 현장 스킵 버그를 되돌려도 **324건이 전부 초록으로 통과**했습니다.

Codex에 후속 라운드를 지시하며 **합격 조건을 "테스트를 늘려라"가 아니라 "그 테스트가 결함을 잡는지
증명하라"로 바꿨습니다** — 지키려는 코드를 고의로 한 줄 망가뜨려 빨강이 뜨는 것을 확인하고 전/후를
보고하게 했습니다. 커버리지가 0/8 → 4/8로 올랐고, 가장 비싼 두 불변식(환불·챕터 게이트)은 이제
기계가 지킵니다.

## 사람이 직접 한 것

**AI에게 무엇을 시키지 않을지 정하는 일**이 사람의 몫이었습니다.

**설계의 경계** — 사건의 진실, 범인·동기·수단, 승패 판정 3축(60/15/15), 콘텐츠 금칙, 그리고 무엇보다
**"AI는 연기하고 진실과 판정은 코드가 소유한다"**는 원칙. 이 게임에서 LLM은 용의자를 연기할 뿐이고,
LLM이 돌려주는 값이 게임 상태로 들어가는 경로는 코드에 아예 없습니다. `AGENTS.md`의 불변식 7개가
그 경계를 문장으로 만든 것입니다.

**검증** — 위의 리뷰·반증·돌연변이 감사를 설계하고 돌렸습니다. 마지막에는 5종의 돌연변이를 각각
독립 사본에서 직접 재현했는데, **2종만 통과하고 3종은 여전히 초록**이었습니다. Codex의 "매번 1건
실패했다"는 보고가 **자기가 고른 지점에서만 참**이라는 뜻이었습니다.

**그래서 이 리팩터링을 머지하지 않기로 결정했습니다.** 코드는 잘 옮겨졌지만 마감 직전에 검증 공백이
60%인 3,133줄을 제출본에 넣을 이유가 없었습니다. 브랜치에 보존하고, 제출본은 검증된 `main`을 유지했습니다.

**UX** — 팀 플레이테스트 피드백(카툰 도입부·브리핑 문안·현장 미리보기·제2막 레이아웃)을 받아
방향을 정하고 구현했습니다. 수사일지를 우측 고정에서 **드로어**로 빼고, 메인을 **녹색 칠판 타임라인**으로
바꾸고, 시스템이 용의자를 자동 소거하던 것을 없앤 판단 — *"용의자가 바로 제외되는 것은 그 용의자에
대한 심문의 기회를 빼앗아간다"*는 지적을 받아들인 것 — 은 전부 사람의 결정입니다.

> **AI에게 얼마나 많이 시켰는지보다, AI가 내놓은 것을 어떻게 검증했는지가 이 프로젝트의 방법입니다.**
> 그 검증이 실제로 한 번은 "머지하지 않는다"는 결론을 냈습니다.
