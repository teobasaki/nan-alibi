# 60초 플레이 영상 — 촬영 대본

> 제출물 ② · 대상 빌드 **https://nan-alibi.pages.dev/?case=gc001**
> 규정: 30~60초 · **실제 플레이 화면 그대로** (AI 합성·타인 영상 도용 불가) · YouTube 공개 또는 링크 공유

---

## 0. 먼저 — "실패 후 성공"으로 짜야 하나?

**아니오. 권하지 않는다.**

실패-재도전 구조는 좋은 서사지만 **60초에는 안 들어간다.** 실패를 보여주려면
최소 15초를 쓰고, 그 15초는 "이 게임은 어렵다"만 남긴다. 심사자는 60초 안에
**이 게임이 무엇인지**를 알아야 하지, 우리가 한 번 틀렸다는 걸 알 필요는 없다.

대신 **한 판의 세로 단면(vertical slice)** 을 보여준다 — 3막이 다 나오고,
마지막에 붉은 인장이 찍히며 끝난다. 실패는 문서(③ 게임 소개)에서 "재도전 가능"
한 줄로 말하면 된다.

> **이 영상이 팔아야 하는 것 세 가지**
> ① 30초라는 압박 → ② AI가 사람처럼 대답한다 → ③ **그 말이 기록과 어긋나는 순간**
> 셋 중 ③이 이 게임의 정체다. 시간을 여기에 가장 많이 준다.

## 2. 컷 구성 (합계 60초)

> **원칙: 한 테이크로 찍는다.** 편집으로 이어붙이면 "조작"으로 의심받을 여지가 생긴다.
> 대신 **게임 안에서 빠르게 넘긴다** — 인트로는 클릭으로 넘어가고, 현장은 30초를 다 쓸 필요가 없다.

| 시각 | 화면 | 조작 | 들려야 할 소리 |
|---|---|---|---|
| **0:00–0:04** | 타이틀 `FIVE ALIBIS` · 사건번호 GC-001 | 2초 정지 후 **[사건 시작]** 클릭 | 빗소리 앰비언스 |
| **0:04–0:09** | 인트로 만화 — 갤러리 저녁 → 받침대 → 발견 | **클릭 3~4번**으로 빠르게 넘긴다 (자동 진행 아님) | 종이 넘기는 소리 |
| 0:09 | — | **Esc** 로 나머지 건너뛰기 | — |
| **0:09–0:13** | 브리핑 「당신이 할 일」 4줄 | 훑고 **[조작법을 본다] → [지금 들어간다]** | 종이 |
| **0:13–0:17** | **붉은 커튼이 닫혔다 열린다** → 제1막 현장 | 없음 (연출) | **커튼 소리** ★ |
| **0:17–0:23** | 훑기 — 카메라가 현장을 돌며 기록을 하나씩 짚는다 | 없음 | 째깍 |
| **0:23–0:33** | **30초 현장** — 1인칭. 마우스로 둘러보며 이동, **증거 2개 수거** | 마우스 시점 + WASD + **E** ×2 | 발소리 · **수거음(셔터)** · 째깍 |
| 0:33 | — | 가방 2칸이 찬 것을 **1초 보여준 뒤** [철수] 또는 시간 종료 | 호루라기 |
| **0:33–0:37** | 커튼 → 제2막 · **용의자 카드 5장이 쫙 펼쳐진다** | 카드 한 장에 마우스를 올려 **뒤집기** 보여주고 클릭 | 커튼 · 카드 |
| **0:37–0:50** | **취조실** — 인물이 앉아 있고, 아래 행동 버튼 | **[사건 시간에 어디 계셨습니까?]** 클릭 → 응답 대기 → 재생 | **AI 음성** ★★ · 타자기 |
| 0:44 | 답변이 타이핑되며 조서 한 줄이 남는다 | 2초 정지 (읽는 시간) | 타자기 · 벨 |
| 0:46 | **[그걸 증명해 줄 사람이 있습니까?]** 한 번 더 | 클릭 | AI 음성 |
| **0:50–0:57** | **대조 → 붉은 인장** ★★★ | 기록 한 장 클릭 → 알리바이 표의 칸 클릭 | **인장 소리(쿵)** |
| **0:57–1:00** | 남은 후보가 줄어드는 것 / 최종 추론 화면 진입 | [최종 추론] 클릭까지만 | 종이 |

### 컷별 주의

- **0:04–0:09 인트로** — 이제 자동으로 안 넘어간다. **클릭 속도가 곧 편집이다.**
  한 컷에 1.2초쯤 머물고 넘긴다. 너무 빨리 넘기면 그림이 안 읽힌다.
- **0:23–0:33 현장** — **30초를 다 쓰지 마라.** 2개만 줍고 나온다.
  회중시계가 줄어드는 게 화면에 보이면 압박은 이미 전달된다.
- **0:37–0:50 심문** — 이 구간이 영상의 핵심이다. 응답이 2초쯤 걸리는데,
  그동안 화면에 **"음… 그게,"** 라는 말버릇이 뜬다 — 그것도 그대로 찍는다.
  기다림이 어색한 게 아니라 **연기의 일부**로 보인다.
- **0:50–0:57 인장** — 여기서 마우스를 천천히 움직인다.
  기록 → 표의 칸 → 인장. 이 세 동작이 **이 게임의 전부**다.

## 4. 소리 녹음 — macOS에서 화면 녹화만으로는 **시스템 소리가 안 잡힌다**

QuickTime 화면 녹화는 기본적으로 **마이크만** 잡는다. 그대로 찍으면 무음 영상이 나온다.
셋 중 하나로 해결한다.

| 방법 | 준비 | 비고 |
|---|---|---|
| **OBS Studio** (권장) | 소스에 `화면 캡처` + `데스크톱 오디오` 추가 | 무료. 오디오 미터로 소리가 잡히는지 **찍기 전에 확인** 가능 |
| BlackHole 등 가상 오디오 | 설치 후 시스템 출력 → 다중출력장치 | 설정이 번거롭다 |
| 아이폰으로 화면 직접 촬영 | 없음 | 최후의 수단. 화질이 떨어져 권하지 않는다 |

**찍기 전 반드시:** 아무 버튼이나 눌러 효과음을 내고 **녹화 미터가 움직이는지** 본다.
1분을 다 찍고 무음인 걸 발견하는 게 가장 흔한 사고다.

**음량 균형** — AI 음성이 가장 잘 들려야 한다. 효과음이 크면 게임 안 `♪` 버튼으로
줄이거나, 편집에서 전체 볼륨만 조정한다(구간별 조작은 하지 않는다).

## 5. 리허설 체크리스트

- [ ] 2회 리허설 — 특히 **현장에서 증거 2개를 8초 안에** 줍는 동선을 손에 익힌다
- [ ] 어느 증거를 주울지 미리 정한다 (가까운 것 2개)
- [ ] 심문할 인물을 정한다 — **류나린**(전시 운영 책임자) 권장. 답이 길고 결이 산다
- [ ] 대조할 조합을 미리 정한다 — 「21:16 기록」 ↔ 그 사람의 21:16 진술
- [ ] 본 촬영은 **한 테이크**. 실수하면 처음부터 다시 (편집으로 잇지 않는다)
- [ ] 찍은 뒤 **소리부터 확인**한다
