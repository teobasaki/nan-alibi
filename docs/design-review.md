# 시니어 아트 디렉터 디자인 리뷰 (gpt-5.6-sol, effort=high)

## 우선순위 1 — 풀숏 구도가 저해상도 인물의 결함을 전부 노출한다  
**[즉시]**

현재 인물은 화면 세로의 약 55%를 차지하면서 손·벨트·좁은 어깨까지 보인다. 특히 **양손의 뭉개진 손가락, 오른쪽 팔의 비정상적으로 곧은 실루엣, 작은 머리와 긴 상체 비율**이 Meshy 모델이라는 사실을 바로 드러낸다. 레퍼런스는 가슴 위 미디엄 클로즈업이라 이런 결함을 숨긴다.

- 카메라 거리: **2.05m → 1.25~1.35m**
- FOV: **46° → 36~38°**
- 측면 오프셋: **0.34m → 0.18~0.22m**
- `lookAt`: 눈이 아니라 **흉골 상단/목 아래 10cm**
- 화면 기준:
  - 눈 높이: 상단에서 **43~46%**
  - 머리 폭: 화면 폭의 **13~16%**
  - 어깨 폭: 화면 폭의 **38~45%**
  - 하단 크롭: **명치~팔꿈치 사이**, 손과 벨트는 전부 프레임 밖
- 현재 상단 중앙의 갓등은 화면 폭 약 38%로 너무 크다. 투영 폭을 **18~22%**로 줄이고 중심을 **화면 x 32~38%, y 8~14%**로 옮겨라. 에셋 스케일을 건드린다면 갓등만 **0.65~0.72배**.

인물 재생성보다 먼저 이 크롭을 적용해야 한다. 현재 모델 결함의 절반 이상은 프레이밍으로 감출 수 있다.

## 우선순위 2 — 얼굴이 정면에서 하얗게 뜨고, 음영은 검게 막혀 얼굴 형태가 사라진다  
**[즉시]**

현재 **이마·코·양 볼이 거의 같은 밝기**라 얼굴이 평면 사진처럼 보인다. 반대로 목 아래와 의자 뒤는 RGB 0에 가까워 명암 사이의 중간 단계가 없다. 레퍼런스는 얼굴 한쪽만 밝고 반대쪽에도 눈·광대 정보가 남아 있다.

- 스포트라이트를 얼굴 정면에서 빼고:
  - 인물 기준 수평 입사각 **50~60°**
  - 위쪽 입사각 **35~45°**
  - 얼굴보다 **0.35~0.5m 옆**, **0.65~0.85m 위**, **0.15~0.25m 앞**
  - 타깃은 얼굴 중심이 아니라 **쇄골 중앙**
- SpotLight 강도: **22 → 13~15**
- ACES exposure: **0.78 → 0.63~0.68**
- HemisphereLight:
  - 강도 **0.35 → 0.10~0.14**
  - sky `0x2c2429 → 0x18202a`
  - ground `0x0a0806 → 0x050403`
- 카메라 쪽에 그림자 복원용 `RectAreaLight` 하나:
  - 색 `0x8fa3b5`
  - 강도 **0.5~0.8**
  - 크기 **1.2 × 0.7m**
  - 인물에서 **1.5~2m**
  - 키 대비 필 비율을 화면 밝기 기준 **약 8:1**로 유지
- 최종 화면 기준 밝은 피부는 **0.55~0.65**, 어두운 얼굴은 **0.06~0.12** 범위로 맞춰라. 피부가 0.8 이상 올라가면 다시 사진 텍스처처럼 뜬다.
- 광원 흔들림: **0.13~0.25rad → 0.015~0.035rad**
  - 두 주기 합산 최대치도 **0.045rad 이하**
  - 현재처럼 얼굴 전체를 왕복해서 훑으면 공포 조명이 아니라 게임 이벤트 조명으로 보인다.

## 우선순위 3 — 벽의 거대한 검은 타원과 인물 뒤 실루엣이 “조명 범위 표시”처럼 보인다  
**[즉시]**

현재 왼쪽 벽의 **검은 반원 경계**는 실제 그림자라기보다 스포트라이트 콘의 끝이 그대로 보이는 형태다. 인물 뒤의 완전한 검은 덩어리도 의자와 인물 그림자가 합쳐져 깊이 정보가 사라졌다.

- SpotLight angle: `π/5.5` 약 32.7° → **π/4.3~π/4.0**, 약 **42~45°**
- penumbra: **0.6 → 0.88~0.94**
- distance: **9 → 5.5~6.5m**
  - 방 전체를 한 콘으로 자르지 말고 인물과 뒤 벽까지만 도달시켜라.
- 실제 광원 위치를 갓 내부 중앙이 아니라 **갓 하단 림보다 5~8cm 아래**로 이동.
- 갓등 메시가 거대한 그림자를 만들면:
  - 갓등 외피 `castShadow = false`
  - 인물·테이블·의자는 유지
- Shadow 설정:
  - 데스크톱 `mapSize`: **2048**
  - 모바일: **1024**
  - `renderer.shadowMap.type = THREE.PCFSoftShadowMap`
  - `shadow.bias = -0.0003~-0.0006`
  - `shadow.normalBias = 0.015~0.025`
  - shadow camera near/far: **0.1 / 6**
- 인물 뒤 검은 덩어리가 계속 남으면 의자만 `castShadow=false`로 테스트하라. 현재 구도에서는 의자 그림자의 정보 가치보다 검은 합성 오류가 더 크다.

## 우선순위 4 — 모든 재질을 `색 ×0.42`, roughness `0.85 이상`으로 통일해 재질 구분이 사라졌다  
**[즉시~중간]**

현재 **피부, 제복, 벽돌, 금속 갓등이 전부 비슷한 매트 표면**으로 반응한다. 갓등은 흰 플라스틱처럼 보이고, 제복은 종이처럼 보이며, 피부에는 이마·코의 좁은 스펙큘러가 없다. 어둡게 만드는 작업을 조명이 아니라 베이스컬러에서 해버린 것이 원인이다.

- 전역 색상 배율: **0.42 → 0.72~0.80**
- roughness 최소 0.85 강제를 제거하고 재질별로:
  - 피부: **0.48~0.62**
  - 머리카락: **0.35~0.48**
  - 제복 천: **0.68~0.82**
  - 벽: **0.76~0.92**
  - 테이블: **0.48~0.65**
  - 금속 갓등: **0.28~0.42**, metalness **0.55~0.8**
- 피부 재질의 `envMapIntensity`: **0.15~0.25**
- 금속 갓등 `envMapIntensity`: **0.5~0.8**
- 컬러스페이스 확인:
  - baseColor/emissive 텍스처: `SRGBColorSpace`
  - normal/roughness/metalness: `NoColorSpace`
  - renderer output: `SRGBColorSpace`
- 얼굴 텍스처가 여전히 하얗다면 피부 머티리얼 컬러만 **`rgb(0.82, 0.72, 0.66)` 정도로 보정**하고 전역 노출을 다시 내리지 마라.
- 현재 뒤 벽의 반복되는 깨끗한 블록에는 **1~2장의 오염 데칼**을 추가:
  - 크기 **0.8~1.4m**
  - opacity **0.22~0.38**
  - 벽에서 **2~4mm** 띄움
  - 최소 한 장은 인물 머리 뒤에 배치해 반복 패턴을 끊어라.

## 우선순위 5 — 인물과 의자·바닥 사이에 접촉 음영이 없어 2D 사진을 세워둔 것처럼 뜬다  
**[중간]**

현재 **턱과 목, 팔과 몸통, 손과 바지, 인물과 의자 접점**에 미세한 차폐가 없다. 대신 멀리 떨어진 벽에는 완전한 검은 그림자만 생겨서 캐릭터가 공간에 붙지 않는다.

`EffectComposer + SSAOPass`를 추가하라.

- 내부 렌더 해상도:
  - 데스크톱: 뷰포트의 **0.75배**
  - 모바일: **0.5배**
- 시작값:
  - `kernelRadius`: **8~12**
  - `minDistance`: **0.002~0.004**
  - `maxDistance`: **0.06~0.10**
  - AO 강도는 최종 합성 기준 **0.55~0.75**
- AO가 얼굴 전체를 더럽히면 얼굴 머티리얼에 적용되는 강도를 **50%**로 줄이고, 목·옷·의자 접점은 유지.
- 테이블을 프레임 하단에 넣는다면 테이블 위 인물 그림자는 반드시 남겨라. 인물 아래 접촉 그림자 면적은 어깨 폭의 **60~80%**, 불투명도는 중앙 **0.3~0.45** 정도가 적당하다.

SSAO를 넣을 시간이 없으면 임시로 의자 좌판과 인물 아래에 투명 블러 원형 평면을 붙여도 된다. 단, 벽에 생긴 거대 그림자를 더 진하게 만드는 방식으로 대체하면 안 된다.

## 우선순위 6 — 비네트가 너무 일찍 시작하고, 공기층과 하이라이트 확산이 없어 검은 마스크를 씌운 화면처럼 보인다  
**[즉시~중간]**

현재 CSS 비네트는 중심 **52%부터** 어두워지고 끝이 `rgba(0,0,0,.6)`라 실제 조명보다 비네트가 먼저 읽힌다. 특히 좌우와 하단이 검게 닫혀 방의 깊이가 사라진다. 반면 갓 전구는 흰 면일 뿐 주변으로 빛이 확산되지 않는다.

- CSS 비네트:
  - 시작점 **52% → 70~74%**
  - 외곽 알파 **0.6 → 0.32~0.40**
  - 원형보다 가로형으로: `ellipse 78% 115%`
  - 중심을 인물 얼굴 쪽인 **55% 46%**로 이동
- `FogExp2`:
  - 색 `0x080b0e`
  - density **0.025~0.04**
  - 인물 얼굴이 회색으로 뜨면 **0.03 이하**
- 전구 주변에 가짜 볼류메트릭 콘 메시:
  - 길이 **1.8~2.5m**
  - 하단 반경 **0.7~1.0m**
  - 색 `0xffc47a`
  - opacity **0.025~0.045**
  - `depthWrite=false`, additive blending
- Bloom을 추가한다면:
  - threshold **0.9~1.1**
  - strength **0.12~0.2**
  - radius **0.25~0.4**
  - 전구와 금속 림만 반응해야 한다. 얼굴까지 번지면 threshold를 올려라.
- 마지막에 단색 그레인 **1.5~2.5%**를 적용. 컬러 노이즈는 사용하지 마라.

### 내일 마감 기준 작업 순서

1. **카메라 크롭과 갓등 화면 크기 수정**
2. **스포트라이트 각도·강도·노출·흔들림 수정**
3. **스포트 콘 경계와 거대 그림자 제거**
4. **전역 `×0.42` 및 roughness 강제 해제**
5. 시간이 남으면 **SSAO**
6. 마지막으로 **비네트·안개·약한 Bloom**

인물 재생성은 하지 마라. 먼저 손과 하체를 프레임 밖으로 제거하고 얼굴 조명을 측면화해야 한다. 그 상태에서도 얼굴 실루엣이나 눈·코 위치가 무너져 보이는 캐릭터만 재생성 대상으로 분류하면 된다.
