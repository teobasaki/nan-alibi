# 3-2-(5) UI 및 디자인

3-2-(5)-(1)  
현재 메인 페이지의 전체적인 디자인 톤이 제각각으로 느껴진다. 도입부 카툰은 종이 질감과 연필 드로잉이 섞인 누아르풍 이미지인데, 메인 페이지의 칠판과 좌측 사이드바, 프로파일링 문서 오브젝트는 서로 다른 게임의 UI처럼 보인다. 특히 칠판은 어두운 취조실의 조명을 받은 수사 보드라기보다는 초등학생 알림장이나 교실 게시판처럼 느껴져, 게임의 무드와 긴장감을 충분히 살리지 못한다. 메인 페이지는 플레이어가 가장 오래 머무는 구간이기 때문에, 이 구간의 시각 톤은 반드시 도입부와 연결되어야 한다.

1단계: 메인 페이지의 시각적 기준점을 도입부 카툰 이미지로 통일한다. 전체 아트 디렉션은 "반실사 카툰 누아르"로 정리한다. 즉, 단순한 카툰도 아니고 완전한 현실풍도 아닌, 현실적인 공간감과 조명 위에 연필선, 종이 질감, 거친 채색이 섞인 스타일을 기본으로 삼는다. 메인 페이지의 칠판, 좌측 사이드바, 우측 수첩, 프로파일링 문서는 모두 이 기준에 맞춰 다시 정리한다.  
2단계: 색상 팔레트도 통일이 필요하다. 도입부처럼 어두운 갈색, 먹색, 바랜 종이색, 탁한 녹색, 붉은 포인트 컬러 정도로 제한해서 사용한다. 지금처럼 요소마다 색감과 재질감이 다르면 화면이 산만해 보일 수 있다.  
3단계: 디자인 가이드 문서를 간단히라도 정리해두면 좋을 것 같다. 예를 들어 "배경은 거친 종이 질감 / 인터랙션 오브젝트는 종이·파일철·칠판 등 아날로그 오브젝트 중심 / 강조 정보는 붉은 계열 사용" 정도의 기준만 있어도 이후 작업에서 톤이 흔들리지 않는다.

3-2-(5)-(2)  
현재 메인 타임라인 보드는 정보 구조 이전에 시각적 분위기부터 아쉽다. 사용 의도는 "어두운 취조실에 조명이 비춰진 알리바이 대조 보드"에 가까운 것으로 보이는데, 지금 결과물은 색감과 질감이 너무 밝고 평평해서 분위기가 약하다. 또한 표의 구성이 현재는 세로가 시간, 가로가 인물인데, 실제로 읽어보면 각 인물의 흐름을 따라가기가 어렵다. 표를 읽는 부담이 커지고, 시선이 위아래로 많이 끊겨서 정보 대조가 직관적이지 않다.

1단계: 메인 보드의 디자인을 현재보다 훨씬 어둡고 무게감 있게 수정한다. 칠판은 탁한 녹흑색 계열로 가고, 표면에는 분필 가루, 지운 흔적, 조명이 닿는 부분의 밝기 차이, 나무 프레임의 질감 등이 느껴져야 한다. 범행 시각은 붉은 분필로 강조하고, 나머지 정보는 흐린 흰색 분필 느낌으로 정리한다. 또한 표의 행과 열을 반대로 바꾼다. 세로에는 용의자, 가로에는 시각이 오도록 구성해서 플레이어가 한 사람의 타임라인을 왼쪽에서 오른쪽으로 따라가며 읽을 수 있게 한다.  
2단계: 현재 표의 칸이 넓고 비어 있는 만큼, 각 칸에 들어가는 정보도 단문 위주로 제한하는 것이 좋다. 예를 들어 장소만 먼저 적고, 추가 정보는 호버나 클릭 시 뜨는 식으로 정리하면 판서처럼 보이면서도 가독성을 유지할 수 있다.  
3단계: 특정 용의자를 클릭했을 때 그 용의자의 행 전체가 조금 더 밝아지거나, 카메라가 살짝 이동하면서 해당 행에 집중되도록 하는 연출도 고려해볼 수 있다. 그러면 타임라인 보드 자체가 단순 배경이 아니라 실제 수사 도구처럼 느껴질 수 있다.

3-2-(5)-(3)  
좌측의 파일철, 우측의 수첩, 중앙의 칠판, 프로파일링 문서가 각각 따로 노는 느낌이 있다. 오브젝트는 많아졌지만, 하나의 세계 안에서 정리된 수사 공간이라기보다는 서로 다른 스타일의 UI를 붙여놓은 것처럼 보일 수 있다. 특히 프로파일링 문서가 추가된 현재 구조에서는, 이 오브젝트들이 전부 같은 사건실 안의 도구처럼 느껴져야 한다.

1단계: 수첩과 파일철, 프로파일링 문서를 모두 "실제 수사 자료를 펼쳐보는 느낌"으로 통일한다. 종이의 바랜 색감, 먹선, 거친 그림자, 손으로 넘기는 듯한 물성 표현을 맞추고, 도입부 카툰의 종이 질감과 같은 시각 언어를 공유하도록 한다. 즉, 파일철은 파일철답게, 수첩은 수첩답게 보이되, 둘 다 같은 세계관의 물건처럼 보여야 한다.  
2단계: 열고 닫히는 인터랙션도 물성에 맞게 들어가면 좋다. 수첩은 옆에서 펼쳐지고, 파일철은 덮개가 열리거나 종이가 드러나는 식으로, 각 오브젝트의 성격에 맞는 애니메이션을 사용한다.  
3단계: 프로파일링 문서와 수사일지 안에 들어가는 아이콘이나 장식 요소도 최소화하는 편이 좋다. 디자인을 살린답시고 장식을 많이 넣기보다, 종이·잉크·분필 자체의 재질감으로 분위기를 만드는 편이 지금 게임 톤에 더 어울린다.

3-2-(5)-(4)  
원하는 카툰 방향성에 대한 기준도 조금 더 명확히 잡을 필요가 있다. 레퍼런스 이미지처럼 완전히 카툰으로 가면 분위기가 너무 가벼워질 수 있다. 반대로 너무 현실적으로 가면 현재 도입부가 가진 삽화적인 매력과 거리감이 생긴다. 지금 게임에는 두번째 레퍼런스의 "넘기는 책, 삽화, 장면 연출"의 감성과, 세번째 도입부 이미지의 "어두운 색감, 현실적인 공간감, 손으로 그린 듯한 질감"이 적절히 섞인 방향이 더 어울린다.

1단계: 스타일 기준은 세번째 도입부 이미지를 우선 기준으로 삼는다. 즉, 메인 화면과 프로파일링 문서, 수사일지의 배경 연출은 도입부처럼 연필선과 종이 질감이 살아있는 반실사 삽화풍으로 맞춘다. 두번째 레퍼런스 이미지는 책장을 넘기는 연출과 삽화형 페이지 구성을 참고하는 용도로만 부분 반영한다.  
2단계: 캐릭터나 오브젝트의 형태는 너무 단순화된 카툰 비율로 가지 않는다. 인체 비율, 실내 공간감, 소품 비율은 비교적 현실적으로 두고, 표면 렌더링과 윤곽선만 삽화적으로 처리하는 방향이 적절하다.  
3단계: 구현 여력이 부족하다면, 모든 화면을 한 번에 바꾸기보다 도입부 → 메인 타임라인 보드 → 프로파일링 문서 순서로 우선순위를 두고 톤을 맞춰나가는 것도 방법이다. 플레이어가 가장 먼저 보고, 가장 오래 보는 화면부터 정리하는 것이 효과가 크다.

3-2-(5)-(5)  
메인 페이지는 단순히 정보가 보이는 화면이 아니라, "심문 전 수사실" 같은 감정이 전달되어야 한다. 지금은 기능은 이해되지만, 조형적으로는 분위기가 약하고, 추리게임 특유의 긴장감이 충분히 살아나지 않는 편이다. 플레이어가 처음 이 페이지에 왔을 때 "이제 진짜 정리하고 파고들어야 한다"는 감각을 받아야 한다.

1단계: 메인 페이지 전체를 "어두운 조사실 안의 알리바이 보드"라는 콘셉트로 다시 정리한다. 중앙은 조명이 떨어지는 대조표, 좌측은 파일철과 용의자 목록, 우측은 수첩이 살짝 튀어나와 있는 구조로, 전체 공간이 실제 수사실 세트처럼 느껴지도록 한다.  
2단계: 배경도 완전히 비워두기보다, 아주 미세하게 어두운 벽면 질감이나 그림자, 조명 번짐 등을 깔아서 공간감을 줄 수 있다. 단, UI보다 튀면 안 되므로 존재감은 약하게 유지한다.  
3단계: 향후 여유가 있다면, 심문실로 들어가거나 프로파일링 문서를 열 때 카메라가 실제로 수사실 안의 다른 자료를 향해 움직이는 듯한 연출도 고려해볼 수 있다. 그렇게 되면 전체 UI가 "화면 위의 메뉴"가 아니라 "사건 공간 안의 인터랙션"처럼 느껴질 수 있다.
