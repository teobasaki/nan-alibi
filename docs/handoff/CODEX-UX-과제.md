## 0. 왜 이걸 고치나

이 게임의 코어 루프는 두 겹이다.

> **① 사람의 말을 듣는다 → ② 그 말을 기록과 맞대어 본다**

①(취조실)은 UI 레퍼런스대로 만들어져 있다. **②가 비어 있다.**
`I` 키로 여는 수첩을 열면 좌면에 *"아직 적을 것이 없다"* 한 줄, 우면에 *"가방이 비어 있다"* 한 줄,
나머지는 **빈 줄만 그려진 종이**다. 추리 게임에서 추리하는 화면이 가장 비어 있다.

심사 기준이 `Presentation` 을 이렇게 정의한다:

> "별도의 설명이 없더라도 게임의 목적, 특징, 매력적인 포인트가 **플레이 경험 안에서** 충분히 드러나는지"

수첩이 비어 있으면 이 게임이 무엇인지가 안 드러난다.

## 1. 이미 있는데 안 쓰는 것 — 여기서 시작하라

**`public/props/thumbs/` 에 증거 썸네일 7종이 구워져 있다. UI 참조 0건이다.**

```
autopsy.webp  call.webp  cctv.webp  crate.webp  keycard.webp  receipt.webp  reel.webp
manifest.json   ← 소품키 → 파일경로 + 증거 종류 대응표
```

3D 소품을 같은 카메라·같은 조명으로 렌더한 「정본 기록 뷰」다.
**현장에서 본 그 물건을 수첩에서 다시 알아보게 하는 것**이 목적이고, 그게 이 게임의
「Living Casebook」 설계다. 지금은 만들어만 두고 안 쓴다.

`manifest.json` 의 `$meta` 에 주의사항이 있다 — 증거 깃발(`flag`)은 프리미티브라 썸네일이 없다.
조회가 비는 경우를 처리하라.

## 2. UX-1 · 수첩 개편 【최우선】

**책 펼침면 은유를 유지한다.** 탭 UI로 바꾸지 마라 — 이 게임의 수첩은 웹사이트가 아니라
형사의 수첩이고, 그게 정체성이다. 대신 **색인 리본**으로 장을 넘긴다.

### 장 구성 (4장)

| 리본 | 좌면 | 우면 |
|---|---|---|
| **개요** | 사건 기본정보 — 날짜·장소·피해자·발생 시각 | 확보 현황 숫자 + 최근 갱신 목록 |
| **기록** | **증거 썸네일 그리드** (§1 에셋 사용) | 고른 증거의 상세 — 큰 썸네일 + 시각·장소·출처 |
| **인물** | 인물 다섯 + 고른 사람의 진술 목록 | **진술 ↔ 기록 좌우 비교** (아래 §2.1) |
| **대조** | 알리바이 대조표 5×5 | 찾아낸 인장 목록 |

### 2.1 진술 ↔ 기록 비교 — 이 게임의 심장

**펼친 책의 두 면이 곧 비교다.** 왼쪽에 그가 한 말, 오른쪽에 기록이 말하는 것.

- 어긋난 칸은 **주황**으로 표시한다. **주황은 오직 "어긋남"에만 쓴다** — 다른 데 쓰지 마라
- 아래에 **무엇이 어긋나게 했는지** 한 줄 (예: `작업 기록 · 21:10 · 메인 전시홀`)
- 이 게임에는 "진술 번복"이 없다(claim 은 시드 고정). **없는 것을 지어내지 마라** —
  비교는 언제나 **진술 대 기록**이지 진술 대 진술이 아니다

### 2.2 빈 화면을 없앤다

지금 가장 큰 문제는 **빈 줄만 남는 지면**이다. 각 장에서:
- 내용이 없으면 **빈 줄을 그리지 말고**, 무엇을 하면 채워지는지 한 줄로 말하라
  (예: 「기록」이 비었으면 → *"현장에서 주운 기록이 여기 쌓인다"*)
- 지면이 남으면 종이가 비어 보이지 않게 여백을 조정하라

## 4. 지켜야 할 것

- **엔진을 건드리지 마라.** 수첩은 상태를 **읽어 그리기만** 한다. 판정·채점은 `src/engine/` 소유다
- **없는 데이터로 UI를 짓지 마라.** 표시할 수치가 없으면 그 칸을 빼라
- 시각·장소 라벨은 `slotLabel(c,t)` / `placeLabel(c,p)` 를 지난다 (불변식 6)
- 새 텍스트는 한국어. **유혈·수단·신체 묘사 금지** (불변식 7)
- 매 커밋 `npm run verify` 초록. 커밋 본문은 실제 개행으로

## 5. 합격 조건

**브라우저로 직접 확인하고 스크린샷을 남겨라.**
- 네 장(개요·기록·인물·대조)이 각각 **비어 있지 않게** 보인다
- 증거를 3개 이상 주운 상태에서 「기록」장에 **썸네일이 뜬다**
- 어긋난 진술이 있는 상태에서 「인물」장이 **좌우 비교와 주황**을 보여준다
- 콘솔 오류 0

"고쳤다"가 아니라 **화면을 보여라.** 이 저장소의 규칙이다(AGENTS.md §4).
