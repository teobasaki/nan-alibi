## 1. 작업 환경 — 어디서 도는가

### GitHub로 관리된다. 단, **오늘 작업은 아직 로컬에만 있다.**

```
원격     https://github.com/teobasaki/nan-alibi.git   (PUBLIC)
기본     main
로컬     /Users/teo/Project/Game/NHN/HusleMusle/nan-alibi
```

| | 상태 |
|---|---|
| `origin/main` | 2026-08-26 14:42 (UTC) 까지 |
| 로컬 `main` | **3커밋 앞섬** — `56e62e0`, `ca3471e`, `82572a1` |
| 워킹 트리 | **미커밋 변경 있음** — `src/main.ts`, `src/style.css` (기능 결함 8건 수리분) |

> ⚠️ **Kiro가 GitHub에서 클론하면 오늘 한 작업을 하나도 못 받는다.**
> 인계 전에 반드시 커밋 + 푸시가 선행되어야 한다. 순서는 §7에 있다.

### 배포

```
프로덕션   https://nan-alibi.pages.dev/?case=gc001     (Cloudflare Pages)
배포 명령   npm run deploy      # = build + wrangler pages deploy dist
```

**배포에는 두 개의 함정이 있고 둘 다 실제로 밟았다.**

1. **`--branch main` 을 붙이지 않으면 프리뷰로 간다.** worktree에서 작업하면 HEAD가 detached라 wrangler가 브랜치명을 `head`로 잡고, 프로덕션이 아닌 프리뷰 별칭에 올린다. 배포는 됐는데 사이트는 그대로인 상태가 된다.
2. **CDN 캐시가 새 배포를 가린다.** 브라우저에서 새로고침해도 옛 번들이 온다.

그래서 규칙이 하나 있다 — **번들 해시를 비교하기 전에는 "배포했다"고 쓰지 않는다.**

```bash
curl -s "https://nan-alibi.pages.dev/?x=$RANDOM" -H 'Cache-Control: no-cache' | grep -o 'index-[A-Za-z0-9_-]*\.js'
```

### 로컬 실행

```bash
npm ci
npm run dev        # http://localhost:5181/?case=gc001
```

`npm run dev`에는 Cloudflare Functions가 없다 → `/api/interrogate`가 404 → **폴백 대사**로 떨어진다. LLM 응답까지 보려면 `.dev.vars`에 키를 넣고 `npm run cf:dev`.

> 🔑 **API 키는 사용자가 직접 넣는다.** 키 값을 채팅·파일·커밋에 절대 노출하지 않는다.
> 그리고 **OpenAI API로 이미지를 생성하지 않는다** (비용). 이미지가 필요하면 ChatGPT 세션에서 만들어 받는다.

## 2. 이 게임이 무엇이고 왜 이 모양인가

**LLM이 용의자 5명을 연기하고, 플레이어는 그들의 말과 객관 기록이 어긋나는 지점을 찾아 범인을 지목한다.**

설계의 헌법은 한 줄이다 — **AI는 연기하고, 사건의 진실과 승패 판정은 코드가 소유한다.** AGENTS.md §2의 불변식 7은 전부 여기서 파생된다. 그중 신입이 가장 자주 어기는 셋:

- **AI에게 `truth`를 주지 않는다.** 프롬프트에는 그 용의자의 `claim`만 들어간다.
- **`Math.random()` 금지.** 같은 시드는 언제나 같은 사건이다.
- **시각·장소 라벨을 하드코딩하지 않는다.** 반드시 `slotLabel()` / `placeLabel()`을 지난다. (GC-001은 21:00~21:21, 호텔 월드는 22:00~22:40 — 하드코딩하면 다른 월드에서 조용히 틀린 시각을 말한다.)

### 현재 사건: GC-001 「갤러리의 사각지대」

라음 사립 갤러리. 피해자 한라온(관장). **범행 21:16 메인 전시홀 · 발견 21:21.** 범인은 **S1 류나린**.
시각 5칸(21:00 / 21:10 / 21:16 / 21:18 / 21:21), 장소 5곳(큐레이터 데스크 / 갤러리 밖 / 메인 전시홀 / 반입문 앞 / 반입대).

### Codex 실험과 그 결과

OpenAI 대회 제출용으로 Codex에게 리팩토링을 맡겼다. Codex는 `AGENTS.md`를 자동으로 읽으므로, 그 파일을 이 실험을 위해 다시 썼다(커밋 `323281f`).

**결과: `refactor/codex`를 머지하지 않기로 했다.** 이유는 감사에서 나왔다 —

- 6축 리뷰 후 각 발견을 반증 검증: 50건 → 32건
- 그다음 **독립 변이 감사**(코드에 일부러 버그를 심고 테스트가 잡는지 확인): 5개 중 **2개만** 잡혔다
- 결정적으로 `src/engine/investigation.ts`는 **어떤 테스트도 import하지 않는다.** 110행에 `throw`를 넣어도 324개 테스트가 전부 초록이었다

그래서 `refactor/codex`는 **머지 대상이 아니라 서술의 증거물**로 남겼다. 제출 문서는 이 감사 자체를 성과로 썼다.

> 여기서 나온 규율이 AGENTS.md §4의 「검증 없이 "고쳤다"라고 쓰지 않는다」다. 이건 장식이 아니라 **실제로 세 번 틀린 뒤에 생긴 규칙**이다.

### 밟았던 함정들 (같은 데 또 빠지지 마라)

| 함정 | 무슨 일이 있었나 |
|---|---|
| **부품이 자기 CSS를 import 안 함** | `caseReview`·`drawer` 둘 다 CSS를 주석으로만 언급하고 import를 안 해서, 화면을 덮거나 문서 흐름에 끼었다. **새 부품을 만들면 그 부품이 자기 CSS를 import한다** |
| **`display: contents`** | `.cb-row`가 이걸 써서 `getBoundingClientRect()`가 전부 0을 돌려준다. 행 단위 측정이 통째로 무의미했다. 측정은 실제 그리드 항목(`.cb-cell` 등)으로 하라 |
| **`all: unset`** | `position`을 `static`으로 되돌린다 |
| **CSS 스코프가 래퍼 하나만 가정** | §4의 최근 blocker가 정확히 이것 |
| **한글 IME와 Enter** | `e.isComposing`을 안 보면 "안녕하세" 상태에서 질문이 잘려 전송되고 **조사 1회가 날아간다** (되돌릴 수 없는 자원) |
| **Cloudflare 25MB/파일** | 51MB 캐릭터 하나가 배포를 통째로 막았다 |

### 기각된 시도

- **gpt-5.4-mini 전환** — 프로덕션 실측 중앙값 2624ms vs gpt-4o 2066ms. **더 느려서** 되돌렸다. 현재 `functions/api/interrogate.ts`의 `MODEL = 'gpt-4o'`.
