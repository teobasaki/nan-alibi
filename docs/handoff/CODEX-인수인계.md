## 2. 과제 — 우선순위 순

### P0 · 제1막 3D 현장이 안 뜬다 【게임이 반쯤 안 보인다】

심사자가 처음 누르는 버튼이 [지금 들어간다]인데, 3D 현장 대신 2D 대조표가 뜬다.
원인은 두 곳으로 좁혀져 있다 — `src/main.ts` 의 `csOpening` 가드가 `.then()` 안에서만 해제되는 것,
`src/ui/curtain.ts` 의 `maxHold` 8초.

> **Codex 프롬프트 초안**
> ```
> src/main.ts 와 src/ui/curtain.ts 에 있는 버그를 고쳐라.
> 증상: [지금 들어간다] 를 눌러도 3D 현장이 뜨지 않고 2D 알리바이 대조표가 보인다.
>       한 번 실패하면 그 세션 내내 다시 시도해도 안 뜬다.
> 가설: (1) csOpening 이 .then() 안에서만 해제되어, mountCrimeScene 이 지연되거나
>       실패하면 영구히 true 로 남는다  (2) curtain 의 maxHold(8000ms) 가 무대보다 먼저 열린다.
> 요구: 원인을 코드로 확인한 뒤 고쳐라. 추측으로 고치지 마라.
>       고치기 전과 후에 브라우저에서 [지금 들어간다] 를 눌러 canvas 생성 여부를 계측하고
>       전/후 수치를 보고에 넣어라. npm run verify 초록 유지.
> ```

### P1 · `src/main.ts` 3,088줄 분해 【테스트 0건 구간】

3,088줄 한 파일에 브리핑·심문·대조표·카드월·결과가 전부 들어 있다.
**단, 이 구간은 테스트가 0건이다.** 특성 테스트 없이 분해하면 조용히 깨진다.

> **Codex 프롬프트 초안**
> ```
> src/main.ts(3,088줄) 를 화면 단위로 분해하고 싶다. 그런데 이 파일은 테스트가 0건이다.
> 1단계: 지금 동작을 박제하는 특성 테스트를 먼저 세워라 (렌더 결과의 구조·분기).
> 2단계: 초록을 유지한 채 화면 단위로 파일을 가른다. 한 번에 한 화면씩, 커밋도 한 화면씩.
> 금지: 동작 변경과 파일 이동을 같은 커밋에 섞지 마라. AGENTS.md §2 불변식을 건드리면 멈추고 보고하라.
> ```

### P2 · 공개 LLM 엔드포인트 방어 【심사 기간 내내 살아 있어야 한다】

`/api/interrogate` 에 인증·레이트리밋·Origin 검사가 없다. 공개 URL이라 제3자가 우리 키를 태울 수 있고,
크레딧이 소진되면 **심사 기간 중 게임이 조용히 열화**된다(폴백 대사만 나오고 화면엔 표시가 없다).

> **Codex 프롬프트 초안**
> ```
> functions/api/interrogate.ts 에 최소 방어를 넣어라: Origin 검사, IP·세션 단위 레이트리밋,
> 그리고 폴백으로 떨어졌을 때 화면에 "AI 응답 실패" 를 정직하게 알리는 경로.
> 제약: 정상 플레이어의 경험을 막지 마라. 로그인은 붙이지 마라(대회 규정상 로그인 필수는 실격 사유다).
> ```

### P3 · 중복 제거 — `bakeWalls` 2곳, DRACOLoader 4곳

## 4. 증빙을 남기는 법 — 이게 점수다

대회 제출 폼에 **`Codex 활용 설명` 자유 서술 5,000자** 칸이 있다(선택·가산점).
로그 파일 업로드란은 없다. 그러므로 **서술이 곧 증빙**이고, 서술을 뒷받침하는 건 **커밋 히스토리**다.

**작업하면서 지킬 것 셋**

1. **Codex가 만든 커밋을 알아볼 수 있게 한다.** 브랜치를 `refactor/codex` 로 두거나
   커밋 본문에 한 줄(`Codex 세션에서 작업`)을 남긴다. 나중에 `git log` 하나로 범위를 보여줄 수 있다.
2. **전/후 수치를 커밋 본문에 적는다.** "고쳤다"가 아니라 "canvas 생성 0회 → 1회",
   "main.ts 3,088줄 → 620줄 + 6파일" 처럼. 심사 서술에 그대로 인용된다.
3. **Codex가 막힌 지점과 사람이 결정한 지점을 메모해 둔다.** 대회가 서술 프레임으로
   네 번째 질문을 명시했다 — *"사람이 직접 결정한 부분은 무엇인가요?"*

**서술 5,000자 골격** (대회가 제시한 4문항 순서 그대로)

| 문항 | 우리가 쓸 내용 |
|---|---|
| ① 어디에 사용했나 | 리팩토링(main.ts 분해)·버그 수리(제1막)·보안(엔드포인트 방어)·테스트 보강 |
| ② 무엇을 구현했나 | 전/후 수치와 커밋 범위 |
| ③ 어떤 문제를 해결했나 | "테스트 0건 구간을 특성 테스트로 감싸고 분해했다" 같은 **방법**을 적는다 |
| ④ 사람이 결정한 것 | 사건의 진실·채점 3축·콘텐츠 금칙·AI에 진실을 주지 않는다는 경계 — **§2 불변식이 곧 답이다** |

> ④가 이 게임의 차별점이다. "AI에게 다 시켰다"가 아니라
> **"AI에게 무엇을 시키지 않을지 정한 것이 설계였다"** 로 쓴다.
