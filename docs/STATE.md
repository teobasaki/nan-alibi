**매 판 다른 사건이 생성되고, 5명의 AI 페르소나를 심문해 3~5분 안에 범인을 지목하는

아래 완료 기준 B 의 "6회" 와 본문 곳곳의 "9회" 는 그 이전 기준이다. 추론도 3축(범인·동기·도구)이 됐다.

끝났다고 말할 수 있는 조건 = 기획서 §6 완료 기준 A~E 전부 통과:
- A. 사건 로직 — 시드 100개 검증 통과율 ≥95%, **최소 조사 수 m\* 가 3~5** (최대 마일스톤)
- B. 게임 규칙 — 조사 6회 예산, 연결 무료, 모순 판정, 채점
- C. AI 계층 — 화이트리스트 검증·폴백 3층·캐시 히트
- D. 성능 — 첫 토큰 ≤1.2s, p95 ≤3.5s, 1판 ≤$0.15, 콘솔 0건
- E. 시간 — 숙련자 1판 ≤5분

## 안 되는 것 / 막힌 것 (정직하게 — "다 잘 됨"이라고 쓰지 마라)

- **프롬프트 캐시가 전혀 안 걸린다.** 입력이 666토큰이라 OpenAI 최소치 1,024를 못 넘긴다.
  비용($0.02/판)·지연(1.7초) 모두 예산 안이라 **의도적으로 방치**한다 (ADR 005). 프리픽스를 억지로 늘리지 않는다
- **E1(플레이 시간) 미측정.** 사람이 한 판을 처음부터 끝까지 돌려봐야 한다
- **캐릭터 품질이 고르지 않다.** 기성 리깅 모델 3종과 Meshy 5종이 섞여 있어 화풍이 안 맞는다.
  Meshy 로는 더 못 올린다 — 이미지 4장 상한 때문에 "선명한 얼굴"과 "온전한 전신"이 동시에 성립하지 않는다
- **Sketchfab 에셋 라이선스 미확인** (취조실 + 캐릭터 3종). 해커톤 제출물이므로 마감 전에 반드시 확인해야 한다
- **TTS 실제 가청 여부 미확인.** 코드는 Yuna 우선으로 붙어 있으나 소리는 사람이 들어야 확인된다
- **로컬 vite dev 로는 AI 경로가 검증되지 않는다.** Cloudflare Function 이 없어 `/api/interrogate` 404 → 폴백 → 조사 환불.
  심문으로 열리는 화면은 **배포본에서** 확인해야 한다
- 표정은 2종(평정/동요)만 있다. 3종째(붕괴)는 미구현
- D2(첫 토큰 ≤1.2초)는 스트리밍 없이 불가 → "응답 완료 ≤2.5초"로 재정의 (ADR 005)
- wrangler 4.x 가 신규 프로젝트에 **Pages 대신 Workers(static assets)** 를 권한다.
  Pages 는 정상 동작하므로 마감 전 전환하지 않는다 — 마감 후 재검토 (ADR 002 에 기록)
