
## 상황판을 세 각도로 (QA 5.4)

인물 × 시각 격자는 이미 있었다. 축을 뒤집은 **장소 × 시각** 표를 더했고, 조서를 사람 단위로 모은 **인물별** 탭을 붙였다.

축을 뒤집으니 인물 격자가 구조적으로 못 보여주던 게 나왔다 — 한 칸에 이름이 모이면 서로의 알리바이고, 한 이름이 같은 세로줄에 두 번 나오면 둘 중 하나는 거짓이다. 배포본 seed=36 에서 실제로 그렇게 읽혔다: 22:00 라운지와 22:30 로비에 서지후·한세아가 함께, 22:20 에는 서지후가 로비(주장)와 복도(CCTV)에 두 번. 1204호 행은 통째로 비어 있다 — 아무도 현장에 있었다고 말하지 않는다.

**모순 판정은 끝까지 안 했다.** 이름을 제자리에 놓는 것까지가 기록 노동이고 두 번 나온 이름을 알아보는 게 추리다. 미대조 조합 목록도 "둘 다 쥐었는데 아직 안 맞춰봤다" 까지만 말한다.

### 걸린 것

- 테스트를 먼저 틀리게 썼다. "아무것도 모르면 표가 비어 있다" 로 짰는데 `createGame` 이 **범행 시각 진술은 처음부터 무료 공개**한다. 코드가 아니라 내 전제가 틀렸다 — 실제 규칙에 맞춰 고쳤다.
- `.chip` 과 `.sheet` 이 이미 다른 용도로 쓰이고 있었다. 새 클래스를 `nchip` · `dossier` 로 바꿨다. **CSS 는 전역이라 이름이 곧 API 다.**
- 로컬 vite dev 에는 Cloudflare Function 이 없어 `/api/interrogate` 가 404 → 폴백 → 조사 환불. 그래서 범행 시각 밖 열이 안 채워졌고 한때 렌더 버그로 의심했다. 배포본에서 조사 9→6 이 깎이는 걸 보고서야 표 전체를 확인할 수 있었다. **AI 경로가 필요한 화면은 로컬에서 끝까지 검증되지 않는다.**
- 인물별 조서에 모순이 안 뜬다고 의심했는데 HMR 리로드로 상태가 초기화된 것이었다. 재현 후 정상 확인.

### 곁가지

`connect()` 가 `"로비이라 했다"` 를 뱉고 있었다. 맞대보기 버튼이 이 문구를 전면에 내세우면서 드러났다 — **UI 를 바꾸면 안 보이던 문자열 버그가 드러난다.** `josa` 를 붙였고, 그 파일이 `src/ui/` 에 있어 엔진이 UI 에 의존할 뻔해서 `src/josa.ts` 로 옮겼다.
