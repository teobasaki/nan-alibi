## 발단 카툰 다중 페이지 검증 + 호텔 인트로 3페이지 전환
- GC001(`?case=gc001`) 3페이지×10칸 전 구간 브라우저 검증: 페이지 넘김(page-out/in), fx, 서술 상자, 진행점 10개, 자동 재생 완주 후 본게임 진입까지 확인.
- 에이전트의 새 시작 페이지(사건 시작 버튼) → 발단 카툰 연결이 이미 HMR로 작동 — playIntro 호출 지점이 유지된 덕.
- 호텔(시드) 인트로를 단일 5칸 페이지 → **3페이지(2+스플래시+2)**로 전환. "한 장에 다 몰아넣었다" 지적의 잔여 과제. playIntro 의 구 재생기 제거, playComicBook 으로 단일화.
- 함정: `.cpage`는 CSS 2열 그리드 — 행 정의가 한 토큰이면(`'p2'`) 칸이 왼쪽 열만 차지한다. 전폭 칸은 `'p2 p2'`로 스팬해야 한다.
- 함정: 앱이 사건 로드 시 URL을 `?seed=N`으로 replaceState — `introhold`/`case` 쿼리가 리로드 후 사라진다. HOLD_MANUAL 은 모듈 로드 시점 평가라 첫 진입은 안전.

## ADR 022 구현 — 챕터 예산·3축 추론·엔딩 (에이전트, 커밋 3개)

  ('autopsy' 물증, 셔플 뒤 append — 주 스트림 보존), 용의자 나이·사정(범인 것이 동기),
  submit 3축(60/15/15) + 통찰 +10 + 잔여 현장 ×2. 봇 재작성, 밸런스 재측정
  (random 22 / common 84 / optimal 100 — 구간 75~95 로 재설정, ADR 023 §3).
- **S2 흐름** (88e8ca6): 시작 페이지(자동 시작 제거, 클릭이 wake 겸용) → 챕터 게이트
  (심문 진입 잠금 + 배너) → 예산 소진 순간 수사 정리 1회 → 심문 화면(나이·관계·대화 n/10 칩).
- **S3 엔딩** (1ec3ff0): 페르소나 8종 결정론 자백(confessions.ts, LLM 아님) ·
  5단계 재구성(발단→전개→위기→절정→결말, 결과 시트 텍스트 타임라인) · 3축 O·X ·
  오답 진단에 부족한 축 안내(비스포일러) · [같은 사건 다시]/[새 게임].
- 브라우저 실확인: seed 36 정답 경로(자백·5단계·100점)와 오답 경로(미제 편철·축 안내),
  게이트 차단 배너, 수사 정리 자동 표시, retry 재로드까지.
- 함정 (ADR 023 에 정리): ① 즉시 조회 기록 4건뿐인 시드 — 예산 0 만으로는 게이트가
  영영 안 열린다 → fieldDone 은 "기록 고갈" OR ② 예산 소진 후 해금 기록은 무료 조회
  (아니면 통찰 보너스가 구조적으로 불가능) ③ 무작위 봇이 지목 사다리를 타면 51% 를
  "추리" — 하한선 의미 복구를 위해 지목도 무작위로.
- 남긴 것: 시작 페이지·게이트·수사 정리는 headless 테스트 없음(main.ts 는 게이트 밖) —
  브라우저 확인으로 갈음. 밸런스 구간 75~95 는 팀 검토 대상 (QUESTIONS Q4).

## GC-001 어댑테이션 — 갤러리 사건이 챕터 엔진 위에서 돈다 (에이전트, 커밋 2개)
- **C1 월드 라벨 간접화** (8ef3c0e): CaseFile.world + slotLabel/placeLabel/kindLabel 헬퍼,
  10파일 치환(프롬프트·검증기 포함 — 호텔 어휘 누출 금지). "결정적=범행 시각·현장" 가정
  제거(플래그 못박기). 게이트 통과: 시드 풀 400개 결정론·기존 228건 무변화.
- **C2 gc001 고정 사건** (923bd0d): src/data/gc001.ts 수제 CaseFile(기록 9건, 결정적은
  은폐 시각 21:18, 열쇠는 기록 2건), ?case=gc001 진입+Retry 유지, ending 오버라이드
  (자백·5단계 결정론), tests/gc001.test.ts 12건(후보 전이 5→3→1, §15.8 붕괴, 금칙어 스캔).
- 실플레이에서 잡은 버그: **예산 0 이면 해금 기록 버튼까지 비활성** — 엔진의 무료 조회가
  화면에서만 죽어 통찰 보너스 도달 불가(호텔도 동일). 헤드리스 테스트는 엔진만 봐서
  못 잡았다 — 버튼 상태는 브라우저만 안다.
- 브라우저 완주: 발단 카툰→현장 5회→수사 정리(후보 3명)→김하늘 제시(실 LLM)→
  무료 해금 2건→후보 1명→3축 100점→gc001 자백·5단계→Retry ?case 유지.
- 계약과 달라진 세부 4건은 ADR 024 에 (ending 필드·Evidence.note·정황 확인 라벨·V3 완화).

## GC-001 본게임 통합 검증 (메인 세션)
- `?case=gc001` 실플레이: 조사 5회(E1·E2·E4·E5·E7) → 후보 {류나린,배지호,문소라} → 류나린 정면 심문
  실 LLM "그게 기록에 있습니까? 전 그런 일을 한 적이 없습니다"(계산적 성향·부인·어휘 누출 0) →
  3축 정답 제출 → 검거 카툰(류나린 이름·직책 정확) → 결과 시트 "사건 완전 해결"+정직한 진단
  ("좁혀서 맞힌 게 아니라 골랐다") + 전용 자백 + 5단계.
- 발견: E3/E6 을 안 열고 예산을 쓰면 결정적 사슬이 그 판에서 닫힌다 — 의도된 전략 선택이고
  결과 시트가 이를 정직하게 짚는다. 버그 아님.
- outro 사건 종속화: 마지막 칸 그림·문장이 사건을 따른다 (gc001=갤러리 외관).
